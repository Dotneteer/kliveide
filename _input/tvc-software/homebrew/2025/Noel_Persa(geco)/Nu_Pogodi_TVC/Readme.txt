TVC/Eneterprise version of 1984 handheld Nu Pogodi!
GFX by Musaic
Code by Geco

Menu Controls:
1   -   Start game A (IGRA A)
2   -   Start game B (IGRA B)
3   -   When it is pressed the game shows Alarm time, when it released the game shows time
4   -   Set time, press key 3 to leave set time mode
5   -   Set alarm time, press 5 to activate/deactivate alarm, press key 3 to leave set alarm mode
Q   -   Increase hour in set time/alarm mode
A   -   Decrease hour in set time/alarm mode
O   -   Increase minute in set time/alarm mode
K   -   Decrease minute in set time/alarm mode

Game Controls
Q   -   Basket left/up
A   -   Basket left/down
O   -   Basket right/up
K   -   Basket right/down
