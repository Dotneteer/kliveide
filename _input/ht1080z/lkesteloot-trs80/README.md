Upstream paths are kept. **Deliberately not copied:**

- `packages/trs80-emulator/src/Model1Level1Rom.ts`, `Model1Level2Rom.ts`, `Model3Rom.ts`,
  `Model3CompiledRom.ts`, `Model4Rom.ts` — these are Tandy/Microsoft ROM images embedded as
  strings ("Generated by convert_roms"). They are not the author's to license; `Trs80.ts` imports
  them, so the copied `Trs80.ts` does not compile on its own (Klive loads ROMs from files anyway).
- `packages/z80-test/z80-tests/tests.in|tests.expected` — the Fuse Z80 test vectors (Fuse is
  GPL-2). `packages/z80-emulator/tests/Fuse.test.ts` (MIT, the harness only) is copied so the way
  the CPU is validated is visible; it needs the vectors from Fuse itself.
- `packages/trs80-base/src/Fonts.ts` — glyph data taken from xtrs (xtrs licence, permissive, but the
  glyphs are character-generator dumps); Klive needs the HT-1080Z character ROM anyway.
- `packages/trs80-cassette/src/LowSpeedTapeDecoder.ts` — says "Originally based on
  https://github.com/anteo/wav2cas", a repository with no licence.
- The web UI (`trs80-emulator-web`, `CanvasScreen.ts` etc.), the IDE, assembler and tools.
