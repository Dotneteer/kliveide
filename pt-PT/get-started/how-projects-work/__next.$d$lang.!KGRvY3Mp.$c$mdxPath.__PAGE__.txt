# Como o Klive trata os projetos

O Klive abre qualquer pasta, mas compila, executa e depura o código de um *projeto Klive*. Esta página explica a diferença e o que o Klive faz quando se abre uma pasta criada com outra ferramenta.

## Uma pasta e um projeto

Um projeto Klive é uma pasta que contém um ficheiro `klive.project`. Qualquer outra pasta é uma *pasta simples*. O Klive abre ambas: o explorador mostra os seus ficheiros, e é possível abri-los e editá-los.

No explorador, um ícone de casa antes do nome da pasta raiz indica que a pasta é um projeto Klive.

## O que um projeto acrescenta

| | Pasta simples | Projeto Klive |
| --- | --- | --- |
| Navegar pelos ficheiros e editá-los | Sim | Sim |
| Usar o emulador, carregar cassetes e instantâneos | Sim | Sim |
| Uma raiz de compilação, e Compilar, Executar e Depurar a partir da barra de compilação | Não | Sim |
| O menu **Compilar** | Não | Sim |
| A máquina e o modelo, repostos ao abrir a pasta | Não | Sim |
| Pontos de interrupção, inspeções e documentos abertos, mantidos entre sessões | Não | Sim |
| **Retirar do projeto** no explorador, e testes unitários | Não | Sim |

A *raiz de compilação* é o ficheiro de código-fonte principal, aquele que o Klive compila.

## Criar um projeto

Escolha **Ficheiro › Novo projeto...**, selecione uma máquina, um modelo e um modelo de projeto, e dê um nome ao projeto. O Klive cria uma pasta com um ficheiro `klive.project`, um script de compilação `build.ksx` e um pequeno programa para começar. A página seguinte, [O primeiro programa em assembly](/pt-PT/get-started/first-assembly-program/), acompanha todo o processo.

## Abrir uma pasta de outra ferramenta

Quando se abre uma pasta sem ficheiro `klive.project` com **Ficheiro › Abrir pasta...**, **Ficheiro › Abrir recente** ou o comando `open`, o Klive pergunta o que fazer com ela. Pergunta também quando reabre uma pasta destas no arranque, por ter sido a última que estava aberta:

<Shot
  src="get-started/make-project.webp"
  alt="A caixa de diálogo Tornar num projeto Klive para uma pasta de ficheiros BASIC, com o modelo zx-basic e main.bas como raiz de compilação"
  figure="5.1"
  caption="O Klive propõe tornar uma pasta simples num projeto Klive"
  markers={["choice", "template", "buildroot"]}
  width={620}
/>

1. **Tornar num projeto Klive**, ou **Manter como pasta simples**.
2. **Modelo de projeto**: o Klive copia os ficheiros do modelo para a pasta: o `build.ksx` de que Compilar, Executar e Depurar precisam, e um programa de exemplo. Para uma pasta com ficheiros BASIC, o Klive escolhe o modelo `zx-basic`; caso contrário, o modelo `default` da máquina.
3. **Raiz de compilação**: o ficheiro que o Klive compila. O Klive lista os ficheiros de código-fonte da pasta e escolhe um deles. Em vez disso, pode escolher **A raiz de compilação do modelo**, o programa de exemplo.

Escolha também o **Tipo de máquina** e o **Modelo**: a caixa de diálogo começa com a máquina que está em execução. Depois, clique em **Criar projeto**. O Klive escreve os ficheiros, reabre a pasta como projeto Klive e abre a raiz de compilação.

Quando um ficheiro do modelo já existe na pasta, a caixa de diálogo lista-o com uma caixa de verificação. O Klive substitui apenas os ficheiros assinalados; os outros ficam como estão.

Para deixar a pasta como está, escolha **Manter como pasta simples** e clique em **Manter pasta**: o Klive memoriza a escolha e não volta a perguntar para essa pasta. [Criar um projeto](/en/guides/projects/creating-projects/#make-a-folder-a-klive-project) indica onde o Klive guarda essa escolha e como anulá-la. **Cancelar** também deixa a pasta como pasta simples, mas o Klive volta a perguntar da próxima vez que for aberta.

Para tornar mais tarde uma pasta simples num projeto Klive, escolha **Ficheiro › Tornar num projeto Klive...**, ou clique com o botão direito na pasta raiz no explorador e escolha **Tornar num projeto Klive...**.

<Callout type="info">
O Klive só altera uma pasta simples quando lhe é pedido. Abrir a pasta e editar os seus ficheiros não escreve nenhum ficheiro `klive.project` nela.
</Callout>

## Os ficheiros que o Klive mantém

- **`klive.project`** guarda a máquina e o modelo do projeto, a sua raiz de compilação, os pontos de interrupção, as inspeções, as definições do projeto e o estado do IDE. O Klive atualiza-o durante o trabalho, por isso não deve ser editado enquanto o projeto estiver aberto.
- **`build.ksx`** contém as funções por trás de Compilar, Executar e Depurar, e do menu **Compilar**. Pode ser alterado à vontade: ver [O sistema de compilação](/en/guides/projects/build-system/).

Mais informação em [Criar um projeto](/en/guides/projects/creating-projects/) e [Modelos de projeto](/en/guides/projects/project-templates/).
