Controls:
Chngmod -   0       Change between Arcade/TVC gfx mode
Start1  -   1       Start 1 player game
Start2  -   2       Start 2 player game
Credit  -   3       Insert coin
DIP3    -   4       00 = 3 ships  10 = 5 ships
DIP5    -   5       01 = 4 ships  11 = 6 ships
DIP6    -   6       Extra ship at 1500/1000 point
DIP7    -   7       Display/do not display coin info on demo screen
TILT    -   8       Enter/Leave to TILT mode
DIP4    -   9       Go to diag ROM (after reset Ü is pressed)
Reset   -   Ü       Resets the program

Player1: 
Left    -   S    / Joy1 left
Right   -   D    / Joy1 right
Fire    -   CTRL / Joy1 fire
Player2: 
Left    -   Á    / Joy2 left
Right   -   Ű    / Joy2 right
Fire    -   ALT  / Joy2 fire
