**The experimental Commodore 64 is removed.** The machine, its 6510 CPU and VIC panels, the
`.6510.asm` file type and its assembler are gone, and Klive no longer ships Commodore 64 ROMs. A
project made for it no longer opens on a machine. A new Commodore 64 on a cycle-accurate core is
planned, with ROMs you supply yourself.
