**Screen file viewer:** `.scr`, `.sl2` and `.nxi` pictures open in one new viewer, and so do LoRes
(`.slr`), Timex hi-colour (`.shc`) and Timex hi-res (`.shr`) files, which only said "not implemented"
before. It fits the picture to the window, lists the file's facts and its PLUS3DOS header, describes
the pixel under the mouse with its bytes and addresses, highlights the pixels of a colour or the cells
that FLASH, blinks FLASH cells as the machine does, and saves the picture as PNG or copies it.
