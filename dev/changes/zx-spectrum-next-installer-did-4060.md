ZX Spectrum Next: the installer did not include the Next's SD card, so on a new installation every
Next model stopped at boot with "Drive C: not found". Klive now installs the card of the ZX Spectrum
Next (KS3, core 3.03.03), which is the default Next model for new projects, and a card image that was
moved or deleted is replaced by the model's own card.
