**Next Registers document:** a pop-out button on the Debug sidebar's Next Registers panel (also View › Machine Views › Next Registers and `show-nextregs`) opens the ZX Spectrum Next's registers as a document. Group them by index or by the book's categories, show values in hex, decimal or binary, filter by number or text, keep only the registers that changed since the previous stop or that the program wrote, and see each register's bits tinted field by field. An inspector column decodes the selected register: both values, a bit diagram, every field with its named values, its categories and the `nextreg` instruction that writes it.
