**TBBLUE.FW viewer**: open the ZX Spectrum Next's firmware file to see its modules, the keys that start each one (Space for the settings menu, U for the updater, C for the extra cores, ...), the firmware version, each module's code as a Z80 disassembly at the address it runs at, and the video test card picture it carries. **Machine › SD Card › Show TBBLUE.FW** (or `show-fw`) opens the firmware on the SD card the Next uses.
