**TBBLUE.TBU viewer**: open the ZX Spectrum Next's core update file to see which cores it carries, for which boards and slots, and where each image sits. The viewer checks every image's checksum as the updater does before it erases a slot, names the FPGA each bitstream is built for, and lists the bitstream's configuration packets. It also reads the older single-core update files.
