**SAM Coupé.** Klive emulates the SAM Coupé 512K and 256K on a new WASM core, with ROM 3.0 or 3.1 (bundled by permission of their author, Andy Wright): the ASIC's four screen modes, palette, line interrupts and memory contention (matching Simon Owen's real-hardware timings), the SAA 1099's stereo sound and the beeper, the keyboard (with an on-screen keyboard drawn from a photo of the machine), mouse and joysticks, two disk drives (.mgt, .dsk, .sad, .sbt images; F9 boots them), and tapes. Run and Debug boot your program from a disk through Klive's own boot loader, so no DOS is needed, and Export writes the same disk as a bootable .mgt. The debugger has ASIC and SAA 1099 panels, execution history, step back and code coverage; the File Manager reads and writes SAM files on MGT disks.
