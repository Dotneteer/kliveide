**The File Manager:** a two-pane file manager (File › File Manager... or `fm`), in the style of Total Commander. Each pane shows a drive: a disk of this computer, the open project, a disk image (`.dsk`, `.trd`, `.scl`, `.mdr`, and the MGT +D/DISCiPLE's `.mgt`), an SD card or hard disk image (`.img`, `.hdf`, `.cim`, each FAT partition and each +3e IDEDOS +3DOS partition a drive of its own), a tape (`.tap`, `.tzx`), or, while the machine is stopped, its own SD card, disks, Microdrives and tape. Copy and move files between any two (F5, F6, or drag and drop), converting each to what the other side keeps: a `.tap` splits into its programs and code on a disk, a `.bas` is tokenised, a program comes back as a one-file `.tap`. Rename, delete, make folders, view a file as a BASIC listing, a screen or bytes (F3), mark files by mask, and reorder a tape. A disk image is written once at the end of a copy, so a cancelled copy leaves it unchanged.
