**Full screen emulator:** **View › Toggle Full Screen** (`Ctrl+Shift+F9`) now fills the screen with
the machine alone: its picture and, when it is shown, the virtual keyboard. The toolbar slides in
when the mouse reaches the top edge of the screen and the status bar when it reaches the bottom,
whether they are switched on or off; they cover the picture without resizing it. The same shortcut
puts the window back as it was. In the IDE window the command still only fills the screen.
