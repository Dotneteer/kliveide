**Advanced debugging in the Settings dialog:** Settings › Debugging has an *Advanced debugging*
switch that turns the execution history, reverse debugging, debug recordings, code coverage and the
profiler on or off, as `set -u features.advancedDebugging` does; the change takes effect when Klive
restarts. *Tint covered source lines* and *Profile hints in the editor* are now on by default.
