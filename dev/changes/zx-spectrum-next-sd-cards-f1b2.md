**ZX Spectrum Next SD cards on demand:** the older Next models' SD cards (NextZXOS 2.08 and 2.10) are downloaded from kliveide.net the first time you select such a model, with a progress bar and Cancel; **Import a downloaded file...** takes a card downloaded in a browser instead. Klive checks every card against its own records before using it. The machine menus, the Select Machine dialog and New Project mark a model whose card must be downloaded, with the size. Before a Next boots, Klive checks its card and, when NextZXOS could not boot it, says why and offers to reset it (keeping the old card under another name), pick another image or go on. Machine › SD Card › Downloaded SD Cards deletes downloaded cards. The DivMMC now has an SD card slot of its own, empty until you insert an image (its menu item is now Remove the SD Card), and the installer carries the default model's card compressed.
