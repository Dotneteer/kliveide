ZX Spectrum Next: interrupt debugging mockups

The Interrupts panel (debug activity, Next only, beside Next Registers and Copper) shows the interrupt system as it stands while the machine is paused. Choose a scenario to see each of the traps from the Interrupts: Fourteen Voices, Two Wires article. Hover a chain row to see Ring (NextReg $20); click a handler address to open the disassembly there. Every value is synthetic.

The Interrupt Timeline document records interrupt events while the machine runs (a ring in the core of 64K events, so the number of frames it holds depends on the program: switch the program to see it) and draws 1, 2 or 4 frames at a time as swimlanes, the way the article draws the nesting figure. Page back to the oldest frame to see one the ring has partly overwritten. A bar is a handler running; a hatched bar is a handler in service but interrupted. Ticks: ▲ request, ● acknowledge, ◆ RETI. Click a bar or a row for details. The data comes from a small daisy-chain simulation.
