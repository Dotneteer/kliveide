# Willkommen bei Klive

Klive ist ein Emulator und eine integrierte Entwicklungsumgebung (IDE) in einer App. Klive emuliert den ZX Spectrum, den ZX Spectrum Next und mehrere weitere Z80-Maschinen, und Sie können darin Programme für diese Maschinen in Z80-Assembler oder ZX BASIC schreiben, erstellen, ausführen und debuggen. Klive läuft unter macOS, Windows und Linux.

<Shot
  src="get-started/debug-paused.webp"
  alt="Die Klive IDE, angehalten an einem Haltepunkt in einem Z80-Assemblerprogramm"
  figure="1.1"
  caption="Die IDE von Klive, angehalten an einem Haltepunkt"
  width={900}
/>

## Zwei Fenster

Klive hat zwei Fenster, die zusammenarbeiten:

- **Der Emulator** zeigt die Maschine: ihren Bildschirm, eine Symbolleiste zum Starten, Pausieren und Anhalten und, wenn Sie möchten, eine virtuelle Tastatur.
- **Die IDE** ist der Ort, an dem Sie Code schreiben: mit einem Projekt-Explorer, einem Code-Editor, einer Befehlszeile und den Debugging-Bereichen, die Register, Speicher und mehr anzeigen.

Sie können die beiden Fenster nebeneinander anordnen oder auf zwei Monitore verteilen.

## Was Sie erwartet

Dieses Tutorial dauert etwa 90 Minuten. Jede Seite baut auf der vorherigen auf, Sie können aber nach jeder Seite aufhören.
