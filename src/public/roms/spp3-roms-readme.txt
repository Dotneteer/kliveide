The v4.0 English set is byte-identical to the plus3-0..3.rom files that the
Fuse emulator distributes under the same Amstrad permission. The version of
the Spanish set was read from its ROM 0 ("SPECTRUM +3 test program V 4.1");
the archive's file name does not say it. Page sizes and CRC32s are checked by
test/machines/p3-rom-images.test.ts.
