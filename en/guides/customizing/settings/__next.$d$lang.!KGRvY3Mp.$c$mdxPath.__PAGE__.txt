# Settings

Klive keeps its preferences in one **Settings** dialog. The menus hold commands &mdash; things that
act now &mdash; and the dialog holds what you set once and forget. This page shows how to open it,
lists its pages, and explains the theme and accent.

<Shot
  src="guides/customizing/settings/settings-dialog.webp"
  alt="The Settings dialog: the search box at the top, the page list on the left, and the options of the selected page on the right"
  caption="The Settings dialog"
  width={760}
/>

## Opening the Settings

| Platform | Menu | Shortcut |
| --- | --- | --- |
| macOS | **Klive › Settings...** | <kbd>Cmd</kbd>+<kbd>,</kbd> |
| Windows and Linux | **File › Settings...** | &mdash; |

Some menus also have an item that opens the dialog on the page you need:

- **Machine › Input › Input Settings...** opens the **Input** page.
- **Machine › Record › Recording Settings...** opens the **Recording** page.
- **Debug › Debugger Settings...** opens the **Debugging** page.

The dialog opens in the window you are working in, the IDE or the emulator, so it works while the IDE
is hidden. The `settings` command opens it from the IDE's command prompt, and `settings <page>` opens
a page, for example `settings machine`.

## How It Works

- **Changes apply immediately.** There is no OK or Cancel button: switch an option and Klive uses it at
  once, just as the menu check items used to. Close the dialog when you are done.
- **Search** with the box at the top. It looks through the options of every page, so you can find an
  option without knowing which page it is on.
- **Reset Page to Defaults** returns every option of the current page to its default value.
- Options that restart the machine, such as a new ROM or another Z88 LCD size, say so in their
  description.

## The Pages

### General

| Option | What it does |
| --- | --- |
| Open the last project at startup | Klive opens the project you used last when it starts. See [The two windows](/en/guides/emulator/emulator-window/#the-two-windows). |
| Close the emulator when the IDE is closed | Closing the IDE window also closes the emulator, and with it Klive. |
| Record tab switches in the navigation history | Clicking a document tab adds a place to the [navigation history](/en/guides/editing/navigation/). |
| Excluded items | **Manage...** lists the files and folders hidden from the Project Explorer. Available while a Klive project is open. |
| Let scripts drive Klive | Opens a local channel for the `klive ide` command line and your own scripts. Any program running as you can use it while this is on. See [Automation](/en/guides/testing/automation/). |
| What scripts may do | **Read** (state, memory and screenshots), **Control** (also run, pause, step, edit memory and build) or **Full** (also any IDE command, which can reach your files). |

### Language

| Option | What it does |
| --- | --- |
| Display language | The language of menus, dialogs and panels, or **System default**. See [The display language](/en/guides/customizing/language/). |
| Translations | How much of the chosen language is translated; **Help translate** explains how to fix a translation or add a language. |

### Appearance

| Option | What it does |
| --- | --- |
| Tone | **Light** or **Dark**. **View › Switch to Light Theme** / **Switch to Dark Theme** flips it from the menu. |
| Accent | The accent colour. See [Theme and accent](#theme-and-accent). |
| Panel font, Panel font size | The font of the IDE's panels. |
| Sidebar on the right | Moves the sidebar to the right side of the IDE window. |
| Command and Output on top | Moves the Command and Output area above the editor. |
| Maximize Command and Output | Lets the Command and Output area take the whole editor area. |

### Editor

The code editor's options: the font family and size, autocomplete, selection and occurrences
highlighting, the quick suggestion delay, detecting the indentation, inserting spaces for a tab,
rendering whitespace, the tab size, and [background compilation](/en/guides/projects/background-compilation).
See [Editing Code](/en/guides/editing/editor/).

### Emulator

| Option | What it does |
| --- | --- |
| Zoom steps | The zoom steps of the emulator screen. |
| Scanline effect | Draws CRT-style scanlines over the picture. |
| Show TV noise without sync | ZX80 and ZX81 only. While the machine sends no usable sync (a ZX81 running a program in FAST mode, a ZX80 computing), shows the noise a real television showed instead of a black screen. Only the display changes, not the machine. |
| Show the snow effect | ZX Spectrum 16K, 48K and 128K. With the I register in contended memory, the CPU's memory refresh disturbs the ULA's screen reads and the picture shows "snow", as on the real machine. On by default. Also **Machine › ZX Spectrum 48K / 128K › Snow Effect**. |
| Late ULA timing | ZX Spectrum 16K, 48K and 128K. Runs the ULA one T-state later against the interrupt, as many real machines do: contention, the screen reads, the border and the floating bus all move by one T-state. Off by default (the documented timings). Also **Machine › ZX Spectrum 48K / 128K › Late ULA Timing**. An `.szx` snapshot sets it to the timing its machine ran. |
| Show the instant screen | See [The paused screen](/en/guides/debugging/paused-screen/). Also a button in the emulator toolbar. |
| Show the beam position while paused | See [The paused screen](/en/guides/debugging/paused-screen/). Also a button in the emulator toolbar. |
| Keep the emulator on top | On by default. See [Keeping the emulator on top](/en/guides/emulator/emulator-window/#keeping-the-emulator-on-top). Also the pin on the emulator toolbar. |
| Show performance info | Shows the emulator's performance figures in its status bar. |
| Show media information | Shows the media strip (tapes, disks, cartridges) in the emulator's status bar. |
| Show the Layers strip | Shows the ZX Spectrum Next's [Layers strip](/en/guides/next/layers) under the screen. |
| ZX Spectrum Next sound output | ZX Spectrum Next only. Which of the Next's outputs Klive plays: the audio jack (the default), the internal speaker or HDMI, each as the real machine builds it. Also **Machine › Sound › Output**. See [The Mixer: One Sum, Three Outputs](/en/under-the-hood/emulator-internals/next-audio/mixer/#how-klive-does-it). |
| Fast load | Loads tapes at once instead of in real time. Also **Machine › Tape › Fast load** and the rocket button on the emulator toolbar. See [Tapes](/en/guides/media/tapes/#fast-load). |

Right-clicking the emulator's status bar toggles the performance info, the media information and the

### Debugging

| Option | What it does |
| --- | --- |
| Stop in interrupt handlers while stepping | Stepping goes into an interrupt routine instead of over it. |
| Stop at runtime errors | The debugger stops where a program raises a runtime error. |
| Just My Code | Stepping steps over code that has no source. |
| Sync the source with the current breakpoint | The editor shows the source line where the machine stopped. Also **Debug › Sync Source with Breakpoint** and an IDE toolbar button. |
| Group breakpoints by kind | Groups the [Breakpoints view](/en/guides/debugging/breakpoints) by breakpoint kind. |
| Reverse debugging | Stepping back puts the whole machine in the past, and you can continue from there. Takes effect at the next debug session. See [Reverse Debugging](/en/guides/debugging/reverse-debugging). |
| Memory for the reverse-debugging timeline | How much memory the timeline may use: *Automatic* (512 MB, or a sixteenth of the computer's memory) or a fixed size. More memory reaches further back. |
| Clear coverage when the machine starts | Coverage and the heat map start over when the machine starts from Stopped. |
| Clear coverage after code injection | The ROM's boot to the injection point does not show as covered. |
| Count executions, reads and writes | Off: only whether each byte was executed, read or written, which costs less. |
| Tint covered source lines | A tinted background in the editor as well as the coverage strip. |
| Profile hints in the editor | Each routine's first line shows its share of the time and its calls. |

The two reverse-debugging rows appear while the [advanced debugging features](/en/guides/customizing/advanced-debugging/)
are on; the five **Coverage and profiling** rows appear on machines with [code coverage](/en/guides/analysis/code-coverage/).

| Scorpion ZS-256 ROM | Scorpion ZS-256 | Names your copy of the Scorpion's 64K ROM. |
| Timex ROM | Timex models | Names your copy of that model's ROM. |
| Keyboard layout | Cambridge Z88 | The Z88's keyboard layout. |
| LCD resolution | Cambridge Z88 | The size of the Z88's screen. Changing it restarts the machine. See [The Cambridge Z88](/en/guides/machines/cambridge-z88/). |

The ROM files have **Browse...** and **Forget** (or **Reset**) buttons; [Custom ROMs](/en/guides/emulator/custom-roms/)

## Theme and accent

The **Theme** group of the **Appearance** page sets how Klive looks:

- **Tone** is **Dark** or **Light**. **View › Switch to Light Theme** (or **Switch to Dark Theme**)
  flips it from the menu.
- **Accent** is the colour of selections, focus and highlights: **Sinclair Blue** (the default),
  **Spectrum Magenta**, **Ember**, **Ultraviolet**, **Deep Teal** or **Phosphor Green**. Any accent
  pairs with either tone.

The accent also reaches the data views: the memory dump, the disassembly and the machine-state panels
pick out their values in it, and the code editor shows keywords in it. The rest of the editor's
colours are fixed, so code stays readable with every accent; see
[Syntax highlighting colors](/en/guides/customizing/syntax-colors/).

## In the Windows Themselves

A few controls moved out of the menus into the part of the window they change:

- The emulator toolbar's **sound** button has a dropdown with the sound levels.
- In the emulator status bar, the **machine name** opens the Select Machine dialog, and the **MHz**
  label opens the list of speeds.
- Right-clicking the emulator status bar toggles the performance info, the media information and the
  Show the Layers strip.
- The IDE toolbar's navigation dropdown has **Clear Navigation History**.

## Where Did It Go?

The menus were reorganised. If you are looking for an item from an earlier version of Klive:

| Earlier menu item | Now |
| --- | --- |
| File › Load ZX Spectrum Snapshot, File › Play RZX Recording, File › Load Machine State | **File › Open File...** (opens snapshots, `.kls` states, `.rzx` recordings and tapes; the same as dropping the file onto the emulator) |
| Machine › Load Snapshot / Load State, Machine › Open Z88 Snapshot, Machine › RZX › Play Recording | **File › Open File...** |
| Machine › Save Snapshot / Save State | **File › Save Snapshot...** / **File › Save Machine State...** |

| IDE › Show Machine Memory / Show Disassembly / Show BASIC Listing | **View › Machine Views › Memory / Disassembly / BASIC Listing** |
