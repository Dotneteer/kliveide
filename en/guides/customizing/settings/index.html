Settings

Klive keeps its preferences in one Settings dialog. The menus hold commands — things that act now — and the dialog holds what you set once and forget. This page shows how to open it, lists its pages, and explains the theme and accent.

Opening the Settings

PlatformMenuShortcut
macOSKlive › Settings…Cmd+,
Windows and LinuxFile › Settings…—

Some menus also have an item that opens the dialog on the page you need:

  • Machine › Input › Input Settings… opens the Input page.
  • Machine › Record › Recording Settings… opens the Recording page.
  • Debug › Debugger Settings… opens the Debugging page.

The dialog opens in the window you are working in, the IDE or the emulator, so it works while the IDE is hidden. The settings command opens it from the IDE’s command prompt, and settings <page> opens a page, for example settings machine.

How It Works

  • Changes apply immediately. There is no OK or Cancel button: switch an option and Klive uses it at once, just as the menu check items used to. Close the dialog when you are done.
  • Search with the box at the top. It looks through the options of every page, so you can find an option without knowing which page it is on.
  • Reset Page to Defaults returns every option of the current page to its default value.
  • Options that restart the machine, such as a new ROM or another Z88 LCD size, say so in their description.

Theme and accent

The Theme group of the Appearance page sets how Klive looks:

  • Tone is Dark or Light. View › Switch to Light Theme (or Switch to Dark Theme) flips it from the menu.
  • Accent is the colour of selections, focus and highlights: Sinclair Blue (the default), Spectrum Magenta, Ember, Ultraviolet, Deep Teal or Phosphor Green. Any accent pairs with either tone.

The accent also reaches the data views: the memory dump, the disassembly and the machine-state panels pick out their values in it, and the code editor shows keywords in it. The rest of the editor’s colours are fixed, so code stays readable with every accent; see Syntax highlighting colors.

In the Windows Themselves

A few controls moved out of the menus into the part of the window they change:

  • The emulator toolbar’s sound button has a dropdown with the sound levels.
  • In the emulator status bar, the machine name opens the Select Machine dialog, and the MHz label opens the list of speeds.
  • Right-clicking the emulator status bar toggles the performance info, the media information and the Show the Layers strip.
  • The IDE toolbar’s navigation dropdown has Clear Navigation History.
