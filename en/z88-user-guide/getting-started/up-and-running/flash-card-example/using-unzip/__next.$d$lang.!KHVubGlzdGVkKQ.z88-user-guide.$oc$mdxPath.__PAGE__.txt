# Using Unzip

## Using Unzip

There are additional applications supplied on the Rakewell flash card that are not in OZ. One of these is Unzip.<br />To demonstrate this Fetch Romcombiner.zip from the flash card.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-flashstore-romcombiner.webp" alt="z88 flashstore romcombiner" width={640} />

Select Unzip <Key k="square" />U or from the INDEX

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-unzip1.webp" alt="z88 unzip1" width={640} />

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-unzip2.webp" alt="z88 unzip2" width={640} />

Use the technique [using the Filer](/en/z88-user-guide/getting-started/up-and-running/flash-card-example/using-pipedream) to select the correct filename.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-unzip3.webp" alt="z88 unzip3" width={640} />

Use the <Key k="enter" /> key to start unzipping.<br />Files may be skipped by selecting the 'n' function

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-unzip4.webp" alt="z88 unzip4" width={640} />

Selecting 'y' unzips the file.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-unzip5.webp" alt="z88 unzip5" width={640} />

Selecting 'y' unzips the file.

All done. Select <Key k="diamond" />Q to Quit this popdown. Press <Key k="menu" /> to see all the commands.
