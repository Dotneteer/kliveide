# Creating Eazylink/Flashstore

<Shot src="z88-user-guide/appendix-i-creating-updating-an-application-card/creating-eazylink-flashstore/oz45-about.webp" alt="oz45 about" width={640} />

<Shot src="z88-user-guide/appendix-i-creating-updating-an-application-card/creating-eazylink-flashstore/eazylink-flashstore-32k-eprom.webp" alt="Eazylink and Flashstore from Rakewell" width={888} />

There are two ways to upgrade your Flashcard

1. Get in touch with [Rakewell](http://www.rakewell.com) who offer the service of <br />upgrading (your own EPROM) or <br />supplying EPROMs with Eazylink & Flashstore.

2. Do it yourself

See [Prerequisites](/en/z88-user-guide/appendix-i-creating-updating-an-application-card#prerequisites)

## Prerequisites

<Callout type="info">

**INFO Put the EPROM in the EPROM ERASER NOW**

If you are going to blow the image into an EPROM card, start erasing it now, as it may take several attempts to erase it completely.

</Callout>

- [Desktop Installation](https://cambridgez88.jira.com/wiki/display/EAZUGV10/Desktop+Installation)
- [Connect the Z88 to the Desktop](https://cambridgez88.jira.com/wiki/display/EAZUGV10/Connect+the+Z88+to+the+Desktop)
- [Starting EazyLink on the Desktop](https://cambridgez88.jira.com/wiki/display/EAZUGV10/Starting+EazyLink+on+the+Desktop)
- Extra RAM fitted in slot 1. Large enough to receive and store all the files required.
- EPROM or Flash card to store the image (as a separate operation)

The Z88 needs to have the following cards as a minimum configuration.

<Shot src="z88-user-guide/external/qg-check-all-z88-cards/128k-ram1-32k-eprom-3.webp" alt="128k RAM Slot 1 32K EPROM Slot 3" width={453} />

- Slot 1 needs to have at least 128K
- Slot 3 has a blank 32K EPROM card to blow the two applications.

The alternative temporary solution is to use the Flash card that OZ will be loaded into. The Z88's configuration is either the 512K/512 RAM/Flash option:-

<Shot src="z88-user-guide/appendix-i-creating-updating-an-application-card/creating-oz/512k-0k-0k.webp" alt="512K/512K RAM/Flash card in slot 1" width={452} />

- Slot 1 has 512K to saves the files into
- Slot 1 also has 512K Flash card to blow the two applications into.

or the 512K RAM (minimum)/1M Flash option:-

<Shot src="z88-user-guide/appendix-i-creating-updating-an-application-card/creating-eazylink-flashstore/512k-ram-1m-flash-0.webp" alt="512K RAM 1M Flash card" width={452} />

- Slot 1 has 512K to saves the files into
- Slot 2 is a 1M Flash card to blow the two applications into.

## First time use

The first time Eazylink is connected to the Z88 the Com Port window is displayed.

<Shot src="z88-user-guide/external/eazugv10-imp-export-mode/imp-exp-compref.webp" alt="ImpExp communications preferences" width={610} />

- Clear the 'Open Serial Port on Startup' tick box<br />Select the 'Default Serial Port:' to the device name the Z88 is connected to.<br />Click the 'Refresh' box and click OK.

An intelligent guess is made at which Serial Port is being used. Here is your chance to check that the correct one has been selected. In this case Windows is using COM 5.

Getting control of Eazylink can be difficult to do initially because Eazylink2 is expecting the pop-down to be running on the Z88. Just keep waiting until you receive the Reading Z88 Devices Command Failed Command Error window.

<Shot src="z88-user-guide/external/eazugv10-imp-export-mode/eazylink-hello-command-failed.webp" alt="eazylink_hello_command_failed" width={487} />

**Choose 'Ignore.'**

What you really need to see is the top Eazylink Menu not being greyed out

## Running RomCombiner

To run the program, do the following:-

- Select BBC BASIC <Key k="square" />B. Type
- RUN "ROMCOMBINER.BAS"

The following screen is displayed.

<Shot src="z88-user-guide/external/qg-check-all-z88-cards/flashtest1.webp" alt="ROMCOMBINER v2.10" width={640} />

EPROMs can only be programmed in Slot 3.

### If an EPROM is being used in slot 3

#### Verify EPROM banks properly erased

<Shot src="z88-user-guide/external/qg-check-all-z88-cards/128k-ram1-32k-eprom-3.webp" alt="128k RAM Slot 1 32K EPROM Slot 3" width={453} />

Press V. followed by

- F
- 32 <Key k="enter" />

If the EPROM is properly erased the following screen is displayed.

<Shot src="z88-user-guide/external/qg-check-all-z88-cards/flashtest4.webp" alt="Verify EPROM properly erased" width={640} />

If an error message is displayed,

<Shot src="z88-user-guide/appendix-i-creating-updating-an-application-card/creating-eazylink-flashstore/not-erased.webp" alt="EPROM not erased" width={640} />

the EPROM should be removed and erased again with the EPROM Eraser until it passes this test.

<Shot src="z88-user-guide/external/qg-check-all-z88-cards/flashtest1.webp" alt="ROMCOMBINER v2.10" width={640} />

### If a Flash card is being used in slot 2

#### Flash EPROM block erase
