## Which version to use?

### Version 4.7.1

Users are able to [download the version that the developers have issued](https://cambridgez88.jira.com/wiki/display/OZ/The+Z88+operating+system)

This version does not have the files required to run RomUpdate. See further down to collect the three extra files.

<Shot src="z88-user-guide/appendix-i-creating-updating-an-application-card/creating-oz/oz45-extra1.webp" alt="OZ 4.5 with extra programs screen1" width={640} />

<Shot src="z88-user-guide/appendix-i-creating-updating-an-application-card/creating-oz/oz45-extra2.webp" alt="OZ 4.5 with extra programs Screen 2" width={640} />

and these files in the file area.

<Shot src="z88-user-guide/appendix-i-creating-updating-an-application-card/creating-oz/oz45-extra-files.webp" alt="Extra filles" width={640} />

to blow it into their own Flash cards.

### Version 5.0 beta

Users are able to download the latest developer builds of OZ ROM and follow the additional instructions on that page - they have been changed.

The current and previous copies including OZ 4.7.1 are further down the page, by using these, you may be able to get back to where you were. Please make Backups of what you do.

There is another way to upgrade your Flashcard should this prove to be difficult.

1. Get in touch with [Rakewell](http://www.rakewell.com) who offer the service of <br />upgrading or supplying Flashcards pre-installed with OZ.

## Prerequisites

- [Desktop Installation](https://cambridgez88.jira.com/wiki/display/EAZUGV10/Desktop+Installation)
- [Connect the Z88 to the Desktop](https://cambridgez88.jira.com/wiki/display/EAZUGV10/Connect+the+Z88+to+the+Desktop)
- [Starting EazyLink on the Desktop](https://cambridgez88.jira.com/wiki/display/EAZUGV10/Starting+EazyLink+on+the+Desktop)
- Extra RAM fitted in slot 1. Large enough to receive and store all the files required.
- EPROM or Flash card to store the image (as a separate operation)

## Preparing the Z88

<Callout type="info">

**IMPORTANT INFO**

The Z88 needs to be running off the internal OZ supplied with the Z88. To ensure that this happens all existing information on the Z88 will be lost after following this procedure. Backup any important files beforehand.

</Callout>

<Callout type="warning">

**Note: Decision Time**

Before you start, you need to decide whether to use the Imp-Export or Eazylink mode. If you choose Eazylink, then you will either have a 32K EPROM card, or it will be blown into the 512K/512K Flash RAM card. See the previous section [Creating Eazylink/Flashstore](/en/z88-user-guide/appendix-i-creating-updating-an-application-card/creating-eazylink-flashstore).

</Callout>

### Execute ROMupdate [#execute]

Press <Key k="diamond" />EX to **EX**ecute or move the cursor back to the left into the command window. then using the <Key k="down" /> key, move the cursor down until that command is displayed in the COMMANDS window, then press <Key k="enter" /> to select it.

The .cli file will be **EX**ecuted and will run the "romupdate.bas" program.

- This program checks that the downloaded files are correct,

<Shot src="z88-user-guide/appendix-i-creating-updating-an-application-card/creating-oz/romupdate-select-slot-1.webp" alt="Select Slot 1" width={640} />

<Callout type="error">

**Sometimes the display looks corrupted**

Sometimes the display looks corrupted. This is normal and you should just WAIT. Eventually you will see a **HARD RESET** and the Z88 will boot into the new copy of OZ created.

</Callout>

- Displays "Select slot to write bank binaries (<Key k="enter" /> to start writing): 1" Select 1 for the 512K/512K Flash/RAM card or 3 for the 1M.
- Erases the Flash card selected slot
- blows the OZ ROM into the card

<Shot src="z88-user-guide/appendix-i-creating-updating-an-application-card/creating-oz/romupdate-end.webp" alt="Romupdate end" width={640} />

- finally, the card is inserted in slot 1 (if not already there), followed by a hard-reset issued by the Z88 user.
- OZ in slot 1 is booted and is ready for use (original ROM in slot 0 is no longer running)

You can check that you have the correct version by selecting the <Key k="help" /> key and then the <Key k="left" /> cursor key to display the version screen as shown at the beginning.

<Callout type="error">

**IMPORTANT:**

**You cannot blow the OZ ROM images to slot 1 if you're already running OZ in that slot.**

</Callout>
