# Section Eight - The Terminal

The Terminal application provides communicating to another device over the RS232 serial line using the Digital VT52 standard protocol.

The Terminal can be entered from the Index APPLICATIONS menu, or by typing <Key k="square" />V.

<Shot src="z88-user-guide/the-terminal/term-main.webp" alt="Terminal - Main Display" width={640} />

The keys typed on the keyboard are sent to the serial port. Some control keys, accessible from the <Key k="menu" /> allow to control output on the remote computer. On the other side, characters received on the serial port are displayed on the Z88 screen and control function allow control of the Z88 screen like layout.

## Serial port settings

The serial port parameters have to match on both computers. They can be configured from the panel which is entered with <Key k="square" />S; see [Panel options](/en/z88-user-guide/using-the-popdowns/the-panel-popdown#serial_port_parameters).

**Exit**

Press <Key k="shift" /> <Key k="enter" /> to exit the terminal and return to the Index. From the Index, move the cursor over the Terminal Suspended Activity and use the <Key k="diamond" />KILL command. This is the preferred option.

### VT52 Control Function Summary

If the following commands are sent to the Serial Port,

their effects are as follows :

| Code sent | Effect |
| --- | --- |
| ESC A | Cursor up |
| ESC B | Cursor down |
| ESC C | Cursor right |
| ESC D | Cursor left |
| ESC F | Enable SOH |
| ESC G | Disable SOH |
| ESC H | Cursor to home |
| ESC I | Reverse Line Feed |
| ESC J | Erase to end of screen |
| ESC K | Erase to end of line |
| ESC L | Clear screen and cursor to home |
| ESC Y row col | Cursor to (row, column) |
| ESC Z | Identify, Z88 responds ESC / Z |

## Spooling files

Material received by the Terminal application can be spooled to a file **:RAM.– /S.sgn** automatically by typing <Key k="square" />**+S** before commencing the transfer. The file will be created in temporary RAM, and should be deleted after use.

Spooling can be disabled by typing <strong><Key k="square" />-S</strong>.

## Transmitting files

A convenient way of sending a file to a remote machine is to copy the file to the **:COM** device.

Enter the Terminal and establish contact with the remote machine in the usual way, and then type <Key k="square" />F to go into the Filer.

Select the file you wish to transmit and then choose Copy from the Filer menu (see Section Seven - Filer Reference, for details of how to select and copy files). A dialogue box will appear. Type in **:COM** as the destination and press <Key k="enter" />. The file will then be transmitted.

Once the transmission is over the dialogue box will disappear leaving the Filer display on the screen. You may then press <Key k="esc" /> to return to the Terminal.

<Callout type="error">

**Only works with TEXT files**

Spooling or Transmitting files only work with TEXT files. If a BINARY file needs to be transferred, use Eazylink2.
