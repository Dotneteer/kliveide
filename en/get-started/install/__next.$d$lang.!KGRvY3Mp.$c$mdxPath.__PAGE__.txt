# Install Klive

Klive is free and open source. Visit the project [release page](https://github.com/Dotneteer/kliveide/releases) to get the install kits for Klive. You find the latest release at the top of the page. When you expand the Assets tab, it lists the installation kits:

- `KliveIdeSetup-{version}-{arch}.AppImage`: The Linux AppImage format to install Klive IDE on Linux without requiring an admin privilege to run
- `KliveIdeSetup-{version}-{arch}.exe`: Self-extracting executable to install Klive IDE on Windows x64 (NSIS installer)
- `KliveIde-Portable-{version}-{arch}.zip`: A Windows x64 archive you unpack and run without an installer (see [Windows without an installer](#windows-without-an-installer))
- `KliveIdeSetup-{version}-{arch}.pkg`: The standard PKG format to install Klive IDE on macOS

`{version}` is a placeholder for the version number of a particular release in the filename.
`{arch}` is a placeholder for the architecture of the target platform. It can be `x64` or `arm64`.

<Callout type="info" emoji="💡">
Windows currently supports only the x64 architecture.
</Callout>

Download the file according to the operating system and architecture to use, and follow the sections of this article.

## macOS

Open the downloaded `.pkg` file. As the file comes from an untrusted source, the OS cannot install it directly. Click the OK button to close the message.

<ClickableImage src="/images/getting-started/warning1.png" alt="Warning1" width={173} height={195} />

Now, open the System Settings panel and navigate to the Privacy & Security tab. As you scroll down, you can see the message with the blocked filename and the Open Anyway button. Click the button to confirm that you intend to run the install kit.

<ClickableImage src="/images/getting-started/privacy-and-security.png" alt="PrivacyAndSecurity" width={477} height={398} />

Open the `.pkg` file again and select the Open button in the security dialog on the screen.

<Callout type="info" emoji="💡">
The OS may ask for your password to confirm the installation.
</Callout>

<ClickableImage src="/images/getting-started/warning2.png" alt="Warning2" width={173} height={233} />

Click Open to allow the installer to run. Follow the screenshots (use Continue) to complete the installation.

<ClickableImage src="/images/getting-started/install-step-1.png" width={413} />

<ClickableImage src="/images/getting-started/install-step-2.png" width={413} />

<ClickableImage src="/images/getting-started/install-step-3.png" width={413} />

<ClickableImage src="/images/getting-started/install-step-4.png" width={413} />

<Callout type="info" emoji="💡">
The installer will create a Klive IDE folder in the Applications folder and copy the required files into it. It will also create a shortcut in the Launchpad. When you complete the installation, macOS may ask you for access to your Downloads folder to move the installer to the Trash.
</Callout>

After the successful installation, you can find Klive IDE in your Applications folder.

<ClickableImage src="/images/getting-started/apps-in-finder.png" width={441} />

## Windows

The `.exe` setup file is a self-extracting executable. Open it, and it will automatically extract itself and copy the executable files into the Programs (within your user home's `AppData/Local/Programs/klive-ide`) directory.

The setup kit will start Klive IDE after completion. Later, you can start Klive IDE again:

Use the search in the Windows taskbar and type "Klive". The newly installed app shows up in the search results:

<ClickableImage src="/images/getting-started/klive-in-search.png" width={213} />

Click on Klive IDE to start it.

<Callout type="info" emoji="💡">
When Klive IDE is selected in the search result list, the right pane shows the Pin to taskbar command. Use this to add the IDE to the taskbar; later, you can run it with a single click on the Klive IDE icon.
</Callout>

### Windows without an installer [#windows-without-an-installer]

If you cannot or prefer not to run an installer (a locked-down machine, no admin rights, or a USB stick), download `KliveIde-Portable-{version}-x64.zip` instead. It needs no setup and writes nothing to the registry.

1. Before extracting, right-click the downloaded `.zip` file, select **Properties**, check **Unblock**, and click **OK**. Without this step, Windows marks every extracted file as downloaded from the internet and may warn you separately for each executable. (In PowerShell: `Unblock-File .\KliveIde-Portable-{version}-x64.zip`.)
2. Extract the archive into a **new, empty folder**: the files sit at the root of the archive, not inside a folder of their own.
3. Run `Klive IDE.exe` from that folder.

This copy is fully portable: it keeps everything it writes in a `KliveData` folder next to `Klive IDE.exe`, and nothing in your user profile.

| Folder | Contents | Installed Klive uses |
| --- | --- | --- |
| `KliveData\Klive` | Settings, the ZX Spectrum Next SD card image, saved files | `%USERPROFILE%\Klive` |
| `KliveData\KliveProjects` | Default location of new projects | `%USERPROFILE%\KliveProjects` |
| `KliveData\KliveExports` | Exported code and screen recordings | `%USERPROFILE%\KliveExports` |
| `KliveData\AppData` | Browser cache and window data | `%APPDATA%\Klive IDE` |

To remove Klive, delete the folder. To upgrade, extract the newer archive into a fresh folder and copy the `KliveData` folder over from the old one to keep your settings.

<Callout type="info" emoji="💡">
The zip copy and an installed Klive do not share settings. To start the zip copy with your existing settings, copy `%USERPROFILE%\Klive` to `KliveData\Klive` before the first run.
</Callout>

<Callout type="warning" emoji="⚠️">
Extract the archive into a folder you can write to. In a read-only location (for example, under `C:\Program Files`), Klive cannot create `KliveData` and falls back to the user-profile folders of an installed Klive.
</Callout>

## Linux

The Linux install kit is an `.AppImage` file. You may need to download and install FUSE on your machine to use it. For example, on Ubuntu (where FUSE is not installed by default), you can install it:

```text
sudo apt-get install fuse libfuse2
```

Copy the `.AppImage` file into the folder from which you intend to use it. Make it executable with this command line:

```text
chmod +x KliveIdeSetup-{version}-{arch}.AppImage
```

Alternatively, you can right-click on the file in the file manager and select the Properties command. In the Permissions tab, check the Allow executing file as program checkbox:

<ClickableImage src="/images/getting-started/ubuntu-permission.png" width={296} />

Then run the file by double-clicking it, or from a terminal with `./KliveIdeSetup-{version}-{arch}.AppImage`.

## The first start

The first time Klive starts, it shows the emulator window with a turned-off ZX Spectrum 48K. Klive may also offer to set up **Boriel BASIC**, an external ZX BASIC compiler. You do not need it for this tutorial: Klive has its own BASIC compiler built in. If you want Boriel BASIC later, the [ZX BASIC guide](/en/guides/languages/klive-basic/#using-boriel-basic) explains how to set it up.
