# Your first ZX Spectrum Next program

The ZX Spectrum Next is a modern ZX Spectrum with a faster Z80 (the Z80N), more memory, and new video hardware: layers, a tilemap, a Copper, and 128 hardware sprites. On this page you put one sprite on the screen and move it across, without drawing a single pixel with the CPU.

## Create the project

Choose **File › New Project...** with these settings:

- **Machine type**: ZX Spectrum Next.
- **Project Template**: `default`.
- **Project name**: `NextSprites`.

## Write the program

Replace the contents of `code/code.kz80.asm` with this program and save it:

```z80klive fixture="next-sprite/code/code.kz80.asm"
; A sprite on the ZX Spectrum Next - the program of Get Started, step 8.
; It uploads one 16x16 sprite pattern and moves the sprite across the screen.

        .model Next
        .org #8000
        .savenex file "NextSprites.nex"   ; the name of the .nex file Klive builds

SPRITE_SLOT  .equ #303b     ; selects the sprite (and pattern) to write
SPRITE_ATTR  .equ #57       ; writes the selected sprite's attributes
SPRITE_PATT  .equ #5b       ; writes the selected pattern's bytes

Start:
        ei
        nextreg #15,%00000001       ; show sprites (on top of the other layers)

        ; Upload pattern 0: 256 bytes, one per pixel
        ld bc,SPRITE_SLOT
        xor a
        out (c),a                   ; pattern 0
        ld hl,Ball
        ld bc,SPRITE_PATT           ; B = 0, so OTIR sends 256 bytes
        otir

        ld d,32                     ; D is the sprite's X coordinate
Move:
        ld bc,SPRITE_SLOT
        xor a
        out (c),a                   ; select sprite 0
        ld a,d
        out (SPRITE_ATTR),a         ; attribute 0: X (low 8 bits)
        ld a,120
        out (SPRITE_ATTR),a         ; attribute 1: Y
        xor a
        out (SPRITE_ATTR),a         ; attribute 2: no palette offset, mirror or rotation
        ld a,%10000000
        out (SPRITE_ATTR),a         ; attribute 3: visible, pattern 0
        halt                        ; one step per frame
        inc d
        jr Move

; The ball: $E3 is the transparent colour, $E0 red, $FF white
Ball:
        .defb $E3,$E3,$E3,$E3,$E3,$E3,$E3,$E0,$E0,$E3,$E3,$E3,$E3,$E3,$E3,$E3
        .defb $E3,$E3,$E3,$E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3,$E3,$E3,$E3
        .defb $E3,$E3,$E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3,$E3,$E3
        .defb $E3,$E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3,$E3
        .defb $E3,$E0,$E0,$E0,$FF,$FF,$FF,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3
        .defb $E3,$E0,$E0,$E0,$FF,$FF,$FF,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3
        .defb $E3,$E0,$E0,$E0,$FF,$FF,$FF,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3
        .defb $E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0
        .defb $E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0
        .defb $E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3
        .defb $E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3
        .defb $E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3
        .defb $E3,$E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3,$E3
        .defb $E3,$E3,$E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3,$E3,$E3
        .defb $E3,$E3,$E3,$E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3,$E3,$E3,$E3
        .defb $E3,$E3,$E3,$E3,$E3,$E3,$E3,$E0,$E0,$E3,$E3,$E3,$E3,$E3,$E3,$E3
```

How it works:

- `.savenex file "NextSprites.nex"` names the `.nex` file that Klive builds and copies to the emulated SD card when you run the program.
- `nextreg #15,%00000001` writes the Next register `$15`, whose bit 0 makes the sprites visible. `NEXTREG` is one of the Z80N's new instructions.
- A sprite's look is its **pattern**: 256 bytes for 16 × 16 pixels, one colour index per pixel. Port `$303B` selects pattern 0, and `OTIR` sends the 256 bytes to port `$5B`. Colour `$E3` is transparent, so the corners of the square do not show.
- A sprite's position is in its **attributes**. Port `$303B` selects sprite 0, and four writes to port `$57` set its X and Y coordinates, its options, and make it visible with pattern 0.
- The loop moves the sprite one pixel to the right every frame. `D` is a byte, so after X = 255 it wraps round to 0.

## Run it

Click **Run**, or press <kbd>F5</kbd>. On the Next, Klive builds a `.nex` file, the Next's program format, and starts it through NextZXOS, the Next's operating system, which boots from an emulated SD card. The first start takes a few seconds; after that, Klive starts from a saved state of the booted system.
