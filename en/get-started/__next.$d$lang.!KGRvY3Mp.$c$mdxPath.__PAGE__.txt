# Welcome to Klive

Klive is an emulator and an Integrated Development Environment (IDE) in one app. It runs the ZX Spectrum, the ZX Spectrum Next and several other Z80 machines, and it lets you write, build, run and debug programs for them in Z80 assembly or ZX BASIC. It runs on macOS, Windows and Linux.

<Shot
  src="get-started/debug-paused.webp"
  alt="The Klive IDE paused at a breakpoint in a Z80 assembly program"
  figure="1.1"
  caption="Klive's IDE, paused at a breakpoint"
  width={900}
/>

## Two windows

Klive has two windows that work together:

- **The emulator** shows the machine: its screen, a toolbar to start, pause and stop it, and, if you want one, a virtual keyboard.
- **The IDE** is where you write code: a project explorer, a code editor, a command prompt, and the debugging panels that show the machine's registers, memory and more.

You can put the two windows side by side, or on two monitors.

## What you will do

This tutorial takes about 90 minutes. Each page builds on the one before it, but you can stop after any of them.
