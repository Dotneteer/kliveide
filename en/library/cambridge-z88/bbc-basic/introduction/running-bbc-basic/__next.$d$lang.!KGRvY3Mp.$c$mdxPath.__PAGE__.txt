# Running BBC BASIC(Z80)

To run BBC BASIC(Z80) for the first time:

- Make sure the INDEX is displayed on your Z88. If necessary, press the <Key k="index" /> key
- Use the cursor keys to select 'BBC BASIC' from the application list
- Press the <Key k="enter" /> key

<Shot src="z88-bbc-basic/introduction/running-bbc-basic/image1.webp" alt="The Z88's Index, with BBC BASIC selected in the Applications list" width={640} />

After a moment, the BBC BASIC application will have started and the interpreter will reply:

<Shot src="z88-bbc-basic/introduction/running-bbc-basic/image8.webp" alt="BBC BASIC's start-up screen" width={640} />

You can now start to use BBC BASIC(Z80).

If you have previously run BBC BASIC(Z80), you can return to it by using the cursor keys to select BASIC from the list of suspended activities list in the INDEX. BBC BASIC(Z80) will appear exactly as you left it.

If you wish, you can have several instantiations (sessions or editions) of BBC BASIC(Z80). Each instantiation will appear in the suspended activities list and you may use the cursor control keys to select the appropriate instantiation.

<Shot src="z88-bbc-basic/introduction/running-bbc-basic/image5.webp" alt="Two BBC BASIC activities suspended in the Index" width={640} />

The easiest way to return to a suspended instantiation of BBC BASIC(Z80) by pressing <Key k="square" />B. If you have more than one suspended instantiation of BBC BASIC(Z80), pressing <Key k="square" />B will return you to the earliest suspended instantiation. Pressing <Key k="square" />B a second time will take you to the next earliest, and so on.
