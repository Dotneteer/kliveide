# Introduction

## Control Codes and Functions [#control-codes-and-functions]

### Generation [#generation]

Control codes are generated by pressing the <Key k="diamond" /> key followed by another key. You don’t need to hold the <Key k="diamond" /> key down. Thus ‘control’ A is generated by pressing the <Key k="diamond" /> followed by the ‘A’ key. ‘Control A’ is shown as <Key k="diamond" />A, etc.

### What happens to Control Codes? [#what-happens-to-control-codes]

In the immediate mode on the BBC Micro, all control codes (with the exception of <Key k="esc" /> and <Key k="diamond" />U) are echoed to the micro’s VDU software where they initiate the same functions as if they had been sent by the VDU statement. This does not happen on the Z88. In the immediate mode and in the response to an INPUT statement, some control codes have a special significance to the input line editor (see later); with the exception of <Key k="esc" />, the others are ignored. All control codes and special function key codes are available to GET and GET$.

Pressing the <Key k="esc" /> key aborts a BBC BASIC(Z80) program or command.

### Pausing the Display [#pausing-the-display]

Holding down the <Key k="diamond" /> and <Key k="shift" /> will pause the output to the screen.

## Line Numbers [#line-numbers]

Line numbers up to 65535 are allowed. If line 65535 does not exist, then GOTO 65535 is equivalent to END. Line number 0 is not permitted.

## Statement Separators [#statement-separators]

When it is necessary to write more than one statement on a line, the statements may be separated by a colon ':'. BBC BASIC(Z80) will tolerate the omission of the separator if this does not lead to ambiguity. It's safer to leave it in and the program is easier to read.

For example, the following will work.

10 FOR i=1 TO 5 PRINT i : NEXT
