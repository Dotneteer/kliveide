# GN_Xdl, Delete an entry from a linked list

## Register parameters

```text
IN:
     CDE = pointer to previous entry
     BHL = pointer to entry to delete
OUT, if call successful:
     Fc = 0
     CDE = pointer to prior entry
     BHL = entry after deleted entry
OUT, if call failed:
     Fc = 1
     A = error code:
          RC_BAD ($04), if BHL(in) = 0

Registers changed after return:
     ...CDE../IXIY same
     AFB...HL/.... different
```

## Notes

Algorithm: Assuming deleting entry I between entries X and Y (for more details, read [Linked lists](/en/library/cambridge-z88/developers-notes/linked-lists)):

`*X = *X XOR I XOR Y`<br />`*Y = *Y XOR I XOR X`
