# OS_Sout, Write local string to standard output

## Register parameters

```text
IN:
  HL = pointer to local null-terminated string

OUT:
   Fc = 0, always (error handler is never provoked)
   HL = points to the null-terminator

Registers changed after return:
   A.BCDE../IXIY same
  .F.....HL/.... different
```

## Notes

- This call replace **[GN\_So](/en/library/cambridge-z88/developers-notes/system-calls-reference/gn-soe)[p](/en/library/cambridge-z88/developers-notes/system-calls-reference/gn-sop)**. This call is shorter (2 bytes) and performs a significantly faster rendering.
- String can cross bank boundary. When string crosses a bank boundary, the bank number of the next segment is used. This feature fixes weird output in BBC Basic when the string crosses a bank boundary.
