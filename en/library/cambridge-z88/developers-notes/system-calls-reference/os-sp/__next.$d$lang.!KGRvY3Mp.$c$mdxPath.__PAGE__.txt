# OS_Sp, Specify

## Register parameters

```text
IN:
     IX = argument
     BC = reason code
     HL = pointer to data
     A = length (size) of data
OUT, if call succeeded:
     Fc = 0

OUT, if call failed:
     Fc = 1
     A = return code:
          RC_BAD ($04), incorrect reason code or parameter
          RC_UNK ($03), unknown request
```

## Notes

Please refer to [OS\_Nq](/en/library/cambridge-z88/developers-notes/system-calls-reference/os-nq) for other system resources that may be only be read.
