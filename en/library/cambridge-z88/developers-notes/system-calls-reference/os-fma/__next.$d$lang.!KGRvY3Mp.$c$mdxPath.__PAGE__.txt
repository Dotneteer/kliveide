# OS_Fma, Find Memory for Allocation

## Register parameters

```text
IN:
	  A = options
        A7 = even bank needed (for segment 0 allocation)
        A6 = fixed memory requested (no subject to swapping)
        A5 = from any slot
		A4 = any offset (generated and returned by call)
        A0-A1 = slot number if A5=0

      H = page offset ($00-$3F; $00 if A4 option set)
      L = number of pages wanted (1 to 64)

OUT:  Fc = 0
         L = 0, always 
         Available memory found at pointer BHL
      Fc = 1, A = RC_Room if not enough space in slot(s)

Registers changed after return:
     ....DEH./IXIY same
     AFBC...L/.... different
```

## Notes

This call tells application in which bank the explicit memory area requested is free for allocation. Refer to **[explicit memory allocation](/en/library/cambridge-z88/developers-notes/memory-management/explicit-memory-allocation)** for further informations. This system call is only available in OZ release V4.6 and newer.
