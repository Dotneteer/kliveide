# OS_Ren, File rename

## Register parameters

```text
IN:
     IX = DOR handle
     HL = pointer to new filename (null-terminated)

OUT, if call successfull:
     Fc = 0
     IX = 0, DOR handle freed
OUT, if call failed:
     Fc = 1
     IX = 0, DOR handle freed

Registers changed after return:
     not documented.
```

## Notes

Internal operating system usage. Applications must use **[GN\_Ren](/en/library/cambridge-z88/developers-notes/system-calls-reference/gn-ren)**.
