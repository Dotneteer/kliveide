# FEP_CDDT ($03), Get Flash Card Data

## Register Parameters

```text
IN:
    A = FEP_CDDT
   HL = Polled from Flash Memory Chip (see FEP_CDID):
        Manufacturer & Device Code

OUT:
   Fc = 0
      ID was found (verified):
      A = chip generation (FE_28F or FE_29F)
      B = total of 16K banks on Flash Memory
      CDE = extended pointer to null-terminated string description of chip
   Fc = 1
     ID was not found

Registers changed on return:
  ......HL/IXIY same
  AFBCDE../.... different
```

## Notes

| $89A7 | "I28F004S5 (512K)" | Intel Flash chip 12V | 8 x 64K sectors |
| $89A2 | "I28F008S5 (1Mb)" | Intel Flash chip 12V, original I28F008SA | 16 x 64K sectors |
| $89A6 | "I28F008S5 (1Mb)" | Intel Flash chip 12V | 16 x 64K sectors |
| $0120 | "AM29F010B (128K)" | AMD Flash 5V | 8 x 16K sectors |
| $01A4 | "AM29F040B (512K)" | AMD Flash 5V | 8 x 64K sectors |
| $01D5 | "AM29F080B (1Mb)" | AMD Flash 5V | 16 x 64K sectors |
