# Flash Card example

The first 4 sections are for first-time users, to give them a taste of how easy it is to use the Z88 using the Flash Card.

The last section is to upgrade your copy of OZ.

- ## [Booting up OZ 4.x using a Flash Card](/en/library/cambridge-z88/user-guide/getting-started/up-and-running/flash-card-example/booting-up-oz-4-x-using-a-flash-card)

This covers getting and installing a 512K/512K Flash/RAM to the Z88 to getting a HARD RESET...

<Shot src="z88-user-guide/external/zp-memory-chips-testing-and-results/hard-reset.webp" alt="hard reset" width={640} />

- ## [Fetching a file from the Flashcard](/en/library/cambridge-z88/user-guide/getting-started/up-and-running/flash-card-example/fetching-a-file-from-the-flashcard)

Get files that are already to use from the Flash Card to RAM so they can be used with other applications.

- ## [Using Pipedream](/en/library/cambridge-z88/user-guide/getting-started/up-and-running/flash-card-example/using-pipedream)

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-pipedream-fl.webp" alt="z88 pipedream fl" width={640} />
