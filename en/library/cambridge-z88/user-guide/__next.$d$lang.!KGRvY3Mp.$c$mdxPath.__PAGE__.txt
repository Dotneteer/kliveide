# Welcome to the Z88 User Guide - edition 4.7

<Callout type="info">

This is the **Cambridge Z88 User Guide**, imported with its author's agreement from the [Cambridge Z88 wiki](https://cambridgez88.jira.com/wiki/spaces/UG/overview). The pages follow the original manual's structure; the conventions it uses for keys, typed text and screen text are explained in [Conventions in this manual](/en/library/cambridge-z88/user-guide/getting-started/conventions-in-this-manual).

</Callout>

<Shot src="z88-user-guide/welcome/user-guide.webp" alt="user guide" width={339} />

This is the revised User Guide for the Cambridge Z88, being updated with all new features and improvements that has been added into the "OZ" operating system ROM, both on application and system level by the Z88 Development Team since the last official V4.0 UK ROM was released by Cambridge Computer in 1989.

The Z88 Development Team reverse-engineered the V4.0 ROM into source code in 2003 and has since then done substantial re-organisation and optimisation of the existing OZ code base, now fulfilled many of the original end-user wishes expressed in the independent end-user "Z88 EPROM" publishing made available in the early nineties.

Per Svensson - a dedicated Z88 user - did all the OCR scanning of the printed 4th edition and converted it to HTML. With his permission, we continued the process, replaced all virtually drawn screenshots with live snapshots from the [Z88 emulator](https://cambridgez88.jira.com/wiki/display/OZVM/OZvm+-+the+Z88+Emulator) and finally converted it into this wiki.

## Major improvements developed since original release by Cambridge Computer

- **[Save and Load Files directly to the File Area](/en/library/cambridge-z88/user-guide/filer-reference#sectionseven-filerreference-devicespecifications)** - no need to save the file to RAM first. Use :EPR:1, 2 or 3 from directly from the Application.

- **[Run Application in RAM](/en/library/cambridge-z88/user-guide/appendix-j-installing-applications-in-ram)** - No need to have applications in Flash or EPROM card, just get and use RAM.

- **[Multiple Language & Keyboard selection](/en/library/cambridge-z88/user-guide/getting-started/up-and-running#changingkeyboardlayout)** - The popular foreign ROM's can now be selected; choose from a range of countries, use different keyboard layouts and see the change of languages in the localized date names in the [Clock](/en/library/cambridge-z88/user-guide/using-the-popdowns/the-clock-popdown#international), [Calendar](/en/library/cambridge-z88/user-guide/using-the-popdowns/the-calendar-popdown#international) and [Diary](/en/library/cambridge-z88/user-guide/using-the-diary#international)

  - Supported languages are:- UK (default) USA, French, German, Spanish, Italian, Danish, Norwegian, Swedish and Finnish

- Filenames may now use the complete ISO character set, allowing to use characters such as **é** and **å** in filenames.

- **[Fast Serial Port](/en/library/cambridge-z88/user-guide/using-the-popdowns/the-panel-popdown#serial_port_parameters)** - all speeds and protocols supported with reliable file transfer up to 38400 baud

- **[Eazylink2](/en/library/cambridge-z88/user-guide/using-the-popdowns/the-eazylink-popdown)** connects to 21<sup><sub>st</sub></sup> century Desktop computers with support for the original file transfer Imp/Export popdown

- [**XMODEM** and **YMODEM**](/en/library/cambridge-z88/user-guide/using-the-popdowns/the-imp-export-popdown#x-y_modem_on_desktop) protocol added to Imp/Export popdown

- **[BBC BASIC V3.10](/en/library/cambridge-z88/user-guide/bbc-basic)**. Now includes the "patch" integration from the V2.2 / V3 UK ROM

- **[Fast Backup](/en/library/cambridge-z88/user-guide/flashstore-reference#backup_files_from_ram) using Flash cards** support in **Filer** and **Flashstore**. Flash cards are FORMATTED by the Z88 itself. - No need to use EPROM Cards or the EPROM Eraser to FORMAT them

- **[Terminal](/en/library/cambridge-z88/user-guide/the-terminal)** supports all VT52 commands

- Main **HELP** pages repopulated and expanded from ROM V3.0 UK (from OZ 4.0)

- **[System Info](/en/library/cambridge-z88/user-guide/using-the-popdowns/the-index-popdown#systeminformation)** page in Index that displays OZ build release information, battery status and free system resources

- **[Alarms](/en/library/cambridge-z88/user-guide/using-the-popdowns/the-alarm-popdown#savingandloading)** can be saved to file (for backup and restore across soft reset)

- [**EPROM**](/en/library/cambridge-z88/user-guide/getting-started/using-cards/flash-and-eprom-cards#epromcardfullyerased) is checked that it is empty before cataloguing the first time
