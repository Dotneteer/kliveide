Settings dialog (Ctrl+, / ⌘,)

One dialog takes every set-and-forget option out of the menu. Its pages are generated from setting-definitions.ts (a new category/group per entry); the few values that live in app state get adapters. Changes apply immediately, as the menu checkboxes do today. The orange tag under each row names the menu path it replaces. Type in the search box to filter across all pages.

Controls that move into the window itself

Frequent, state-like choices go where the user is already looking: the emulator toolbar and the status bar. The menu keeps the command, so keyboard and menu users lose nothing. Hover the green-outlined controls.

Sound level dropdownThe mute/unmute button gains a caret: a slider with the five levels. Machine › Sound stays as the keyboard path.
Record dropdownThe record button offers the three kinds of recording and “Recording Settings…”. Format, quality, fps and the IDE + Emulator options leave the menu.
Machine name and MHz are clickableThe status bar already shows both; clicking opens the favourites + “Select Machine…” and the clock multiplier.
Status bar context menuRight-click (or click the performance chip) toggles the status-bar extras: performance info, media strip, Next layers strip.
Layout lives with the layoutRight-click the activity bar: “Move Sidebar to the Right”. The Command & Output header gets “Move to Top” and “Maximize” buttons.
Layers strip already owns layersShow/Solo per layer, transparency, clip windows and the pixel probe are all on the strip; the 16-item Machine › Layers submenu goes.
