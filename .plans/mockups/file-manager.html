Klive File Manager: mockups

A two-pane file manager in the style of Total Commander, opened as an IDE document. Each pane shows one drive: a folder on this computer, the project, a disk image, an SD card image, a tape, or the stopped machine's own storage. Plan: .plans/FILE_MANAGER_PLAN.md.

The left pane is the project on the host; the right pane is the stopped ZX Spectrum Next's SD card (machine storage, the purple dot). Two files are marked (orange) for copying; the cursor is on the active pane's row. Columns follow the drive's file system.

Keys (Total Commander)Tab switches pane · Insert/Space marks · +/− mark by mask · Enter opens a folder or enters an image · Backspace goes up · Alt+F1/F2 drive menus · Ctrl+R refreshes.
DrivesThis computer, Project, Machine storage (stopped machine only), Disk images (.dsk .trd .scl .mdr .img .hdf .cim, one drive per FAT partition) and tapes (.tap, .tzx read-only).
SafetyPlan before write: names, conflicts and free space are checked first. An image is written once per job; a cancelled job leaves it unchanged. Host deletes go to the trash.
