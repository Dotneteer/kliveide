Sprite Inspector — G3.2 sprite table + G3.3 pattern memory in one document

Mockup for .plans/SPRITE_INSPECTOR_PLAN.md. A ZX Spectrum Next game paused at a breakpoint. Everything below is clickable: select a sprite row, a pattern cell or an outline on the sprite-space map; switch the view, the pattern format, the palette-offset mode and the zoom; show the raw attribute bytes.

1 · The document, paused mid-frame

Sprite #12 is selected: rotated, X-mirrored and scaled 2×. Its pattern is outlined in the sheet. The orange dots mark rows whose bytes changed since the previous stop (Q7, a new treatment). Purple sheet borders mark patterns that the selected sprite reads.
