# Design: Klive IDE website

The locked system of the website (`docs/`): the landing page and the documentation. Hallmark reads
this first when it is run from this folder, and every page shares it; it never deals a theme here
(`.plans/HALLMARK_SITE_POLISH_PLAN.md`, H1 and H3). Change it on purpose; the file is the rule.
The reasons behind each rule are in `.ai/ui-theming-intent-and-lessons.md` ("The Website Wears The
App's Palette"); where the two differ, that file wins and this one is corrected.

## System
- Genre: modern-minimal (a developer tool), with a long-document body for the docs.
- Shape of the landing page: a data sheet (`.plans/DOCS_SITE_REDESIGN_PLAN.md`, R3): headline
  beside an "At a glance" table, the screenshot carousel full width, tables (machines, also
  included, write/build/run/debug), feature rows always text left and picture right.
- Theme: custom, the app's own palette (vibe: "the IDE's own colours, a data sheet").
- Posture: restrained. The one accent is Sinclair Blue; the four Spectrum colours appear only as
  the 6px rule at the top of the landing page and the square before each feature label, never as a
  band, a block or behind running text.

## Tokens
`docs/app/tokens.css` is the source of truth, and `test/docs/site-tokens.test.ts` keeps it equal to
the app's L1 values (`src/renderer/theming/tokens/palette.ts`). The light theme is derived from the
dark one the way the app derives it; never tune one by hand. The roles:
- Paper: `--site-bg`, `--site-panel`, `--site-chrome`, `--site-raised`, `--site-hover`
- Ink: `--site-fg` (body text, full colour), `--site-muted` and `--site-subtle` (secondary details only)
- Rules: `--site-line`, `--site-line-strong`; sections are divided by a 2px rule in the text colour
- Accent: `--site-accent`, `--site-on-accent`, `--site-accent-soft`
- Spectrum: `--site-stripe-*` (the rule), `--site-spectrum-*` (the feature squares)
- Type: `--site-font-display` and `--site-font-body` are both Overpass, with its real italic;
  `--site-font-mono` is Overpass Mono, for code and values (a version number, a file name) only.
  The fonts are committed (`docs/fonts/`), generated into `docs/app/fonts.ts`.

## Type
- Headings 700, normal letter spacing, one colour.
- Labels are bold body type in sentence case: never uppercase, never letter-spaced, never mono.
- Links are underlined, without arrows.

## Controls
- Button (`.lp-button`): 1px `--site-line-strong` border, 6px radius, weight 600, never wraps.
  The primary (Download) fills with the accent.
- Small controls (carousel arrows, dots, theme toggle): 2rem square, 6px radius, hover on
  `--site-hover`.

## Pictures
- Real screenshots only, generated by `scripts/doc-shots/` recipes (`landing.cjs` for the landing
  page, `guides-*` for the guides). Docs screenshots are dark whatever the page's theme.
- Every landing picture is a plain link to its file and opens in the inset viewer
  (`docs/landing/ImageViewer.tsx`): fitted, never scrolled.

## Motion
- Character: calm. The carousel advances every five seconds and stops only by its pause button;
  reduced motion turns off the flying, not the advancing. Transitions list their properties
  (background, filter, opacity), 0.15s; under reduced motion they end at once.
