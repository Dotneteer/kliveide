# O primeiro programa para o ZX Spectrum Next

O ZX Spectrum Next é um ZX Spectrum moderno, com um Z80 mais rápido (o Z80N), mais memória e novo hardware de vídeo: camadas, um tilemap, um Copper e 128 sprites de hardware. Nesta página, coloca-se um sprite no ecrã e desloca-se de um lado ao outro, sem desenhar um único pixel com a CPU.

## Criar o projeto

Escolha **Ficheiro › Novo projeto...** com estas definições:

- **Tipo de máquina**: ZX Spectrum Next.
- **Modelo de projeto**: `default`.
- **Nome do projeto**: `NextSprite`.

## Escrever o programa

Substitua o conteúdo de `code/code.kz80.asm` por este programa e guarde-o:

```z80klive fixture="next-sprite/code/code.kz80.asm"
; A sprite on the ZX Spectrum Next - the program of Get Started, step 8.
; It uploads one 16x16 sprite pattern and moves the sprite across the screen.

        .model Next
        .org #8000

SPRITE_SLOT  .equ #303b     ; selects the sprite (and pattern) to write
SPRITE_ATTR  .equ #57       ; writes the selected sprite's attributes
SPRITE_PATT  .equ #5b       ; writes the selected pattern's bytes

Start:
        ei
        nextreg #15,%00000001       ; show sprites (on top of the other layers)

        ; Upload pattern 0: 256 bytes, one per pixel
        ld bc,SPRITE_SLOT
        xor a
        out (c),a                   ; pattern 0
        ld hl,Ball
        ld bc,SPRITE_PATT           ; B = 0, so OTIR sends 256 bytes
        otir

        ld d,32                     ; D is the sprite's X coordinate
Move:
        ld bc,SPRITE_SLOT
        xor a
        out (c),a                   ; select sprite 0
        ld a,d
        out (SPRITE_ATTR),a         ; attribute 0: X (low 8 bits)
        ld a,120
        out (SPRITE_ATTR),a         ; attribute 1: Y
        xor a
        out (SPRITE_ATTR),a         ; attribute 2: no palette offset, mirror or rotation
        ld a,%10000000
        out (SPRITE_ATTR),a         ; attribute 3: visible, pattern 0
        halt                        ; one step per frame
        inc d
        jr Move

; The ball: $E3 is the transparent colour, $E0 red, $FF white
Ball:
        .defb $E3,$E3,$E3,$E3,$E3,$E3,$E3,$E0,$E0,$E3,$E3,$E3,$E3,$E3,$E3,$E3
        .defb $E3,$E3,$E3,$E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3,$E3,$E3,$E3
        .defb $E3,$E3,$E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3,$E3,$E3
        .defb $E3,$E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3,$E3
        .defb $E3,$E0,$E0,$E0,$FF,$FF,$FF,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3
        .defb $E3,$E0,$E0,$E0,$FF,$FF,$FF,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3
        .defb $E3,$E0,$E0,$E0,$FF,$FF,$FF,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3
        .defb $E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0
        .defb $E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0
        .defb $E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3
        .defb $E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3
        .defb $E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3
        .defb $E3,$E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3,$E3
        .defb $E3,$E3,$E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3,$E3,$E3
        .defb $E3,$E3,$E3,$E3,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E0,$E3,$E3,$E3,$E3
        .defb $E3,$E3,$E3,$E3,$E3,$E3,$E3,$E0,$E0,$E3,$E3,$E3,$E3,$E3,$E3,$E3
```

Como funciona:

- `nextreg #15,%00000001` escreve no registo do Next `$15`, cujo bit 0 torna os sprites visíveis. `NEXTREG` é uma das novas instruções do Z80N.
- O aspeto de um sprite é o seu **padrão**: 256 bytes para 16 × 16 pixels, um índice de cor por pixel. A porta `$303B` seleciona o padrão 0, e `OTIR` envia os 256 bytes para a porta `$5B`. A cor `$E3` é transparente, por isso os cantos do quadrado não aparecem.
- A posição de um sprite está nos seus **atributos**. A porta `$303B` seleciona o sprite 0, e quatro escritas na porta `$57` definem as coordenadas X e Y, as opções, e tornam-no visível com o padrão 0.
- O ciclo desloca o sprite um pixel para a direita em cada fotograma. `D` é um byte, por isso, depois de X = 255, volta a 0.

## Executar

Clique em **Executar**, ou prima <kbd>F5</kbd>. No Next, o Klive cria um ficheiro `.nex`, o formato de programa do Next, e inicia-o através do NextZXOS, o sistema operativo do Next, que arranca a partir de um cartão SD emulado. O primeiro arranque demora alguns segundos; a partir daí, o Klive arranca a partir de um estado guardado do sistema já iniciado.
