# Willkommen bei Klive

Klive ist ein Emulator und eine integrierte Entwicklungsumgebung (IDE) in einer App. Klive emuliert den ZX Spectrum, den ZX Spectrum Next und mehrere weitere Z80-Maschinen, und Sie können darin Programme für diese Maschinen in Z80-Assembler oder ZX BASIC schreiben, erstellen, ausführen und debuggen. Klive läuft unter macOS, Windows und Linux.

## Fenster und Monitore

Klive startet mit zwei Hauptfenstern, die zusammenarbeiten:

- **Der Emulator** zeigt die Maschine: ihren Bildschirm, eine Symbolleiste zum Starten, Pausieren und Anhalten und, wenn Sie möchten, eine virtuelle Tastatur.
- **Die IDE** ist der Ort, an dem Sie Code schreiben: mit einem Projekt-Explorer, einem Code-Editor, einer Befehlszeile und den Debugging-Bereichen, die Register, Speicher und mehr anzeigen.

Sie sind nicht auf diese beiden beschränkt. Klicken Sie in der IDE mit der rechten Maustaste auf die Registerkarte eines Dokuments und wählen Sie **Pop Out to Window**, um das Dokument in ein eigenes Fenster zu verschieben, zum Beispiel eine Quelldatei, die Ansicht **Speicher** oder die Ansicht **Disassemblierung**. Bis zu vier Dokumente können gleichzeitig ein eigenes Fenster haben. Ein abgekoppeltes Dokument funktioniert wie in der IDE, mit seinen Haltepunkten, dem Ausführungspunkt und seinen Tastenkürzeln, und seine Schaltfläche **Dock** bringt es in die IDE zurück.

Klive nutzt alle Monitore, die Ihr Computer hat. Sie können den Emulator auf einem Bildschirm lassen, die IDE auf einem anderen und den Code, den Sie gerade debuggen, neben dem Emulator. Klive merkt sich, wo seine Fenster waren, und öffnet sie beim nächsten Mal wieder dort. Einzelheiten finden Sie unter [A document in its own window](/en/guides/editing/editor/#a-document-in-its-own-window).
