# Machine Types

This document summarizes the machines and models available in Klive IDE.

## Choosing a machine

The **Machine | Machine type** menu lists only your *favourite* models, followed by **Select machine…** (**Cmd+Shift+M** on macOS, **Ctrl+Shift+M** on Windows and Linux). If the machine you are running is not a favourite, the menu still shows it, ticked, below the favourites.

**Select machine…** opens a dialog with every model Klive emulates:

- The left side lists the machine types; open one to see its models. The filter box at the top matches names and hardware facts, so typing `128K`, `NTSC`, `disk` or `OZ` narrows the list.
- Selecting a model shows its hardware details on the right: CPU and clock, ROM and RAM, the screen (resolution, colours, the visible area with its border), frame timing, sound devices, storage and input.
- **Switch to …** (or double-clicking a model, or pressing **Enter**) switches the emulator to it.

The dialog also edits the menu. Click the star next to a model, or **Add to Machine type menu** above its details, to make it a favourite. The **Favourites** section at the top lists them in menu order: drag them, or use the arrow buttons (**Alt+↑** / **Alt+↓**), to reorder them, and use the separator button to put a menu separator after an item. **Save** keeps the changes; **Restore default favourites** brings back the original list. Favourites belong to you, not to a project.

## ZX Spectrum 48K

Machine ID: `sp48`

Available models:
- `pal`: The original ZX Spectrum 48K model with PAL video output.
- `ntsc`: The original ZX Spectrum 48K model with NTSC video output.
- `pal-16k`: The original ZX Spectrum 48K model with PAL video output and 16K RAM.

## ZX Spectrum 128K

Machine ID: `sp128`

One machine with two models. Both run the ZX Spectrum 128K's ROMs and have its `$7FFD` paging and
AY chip; they differ in timing:

- `sp128`: The original ZX Spectrum 128K.
- `pentagon`: The Pentagon 128, a Russian 128K clone much of the demoscene writes for. It runs at
  3.5 MHz with a longer frame (224 T-states by 320 lines, 71,680 T-states, about 48.8 frames per
  second), has no memory or I/O contention, and has no floating bus: an unattached port reads `$FF`.

**Which one to pick.** Choose the Pentagon for software written for it, such as demos whose effects
are timed to its frame, or to check that your own code runs on both machines. Choose the 128K for
everything else. Running, debugging, injecting code, the tape Loader, snapshots and Klive state
files work the same on both.

The Pentagon model does not have the Beta 128 disk interface yet, so TR-DOS and `.trd`/`.scl` disk
images are not available. A 128K `.sna` snapshot that has the TR-DOS ROM paged in loads with a
warning.

A `.z80` or `.szx` snapshot of a Pentagon 128 opens on the Pentagon model. A 128K snapshot opens on
the 128K model, unless your project already uses the Pentagon: a 128K `.sna` file does not say
which of the two machines it came from. A snapshot saved from the Pentagon is written as a Pentagon
128.

## ZX Spectrum +2A/+3/+2E/+3E

Machine ID: `spp3e`

One machine with two families of ROMs. The hardware is Amstrad's +2A/+3 (the gate array, the
`$7FFD`/`$1FFD` paging, the floppy controller and the AY chip) in every model; the models differ in
their drives and in the ROMs they boot.

The +2E/+3E models boot Garry Lancaster's +3E ROMs, a modern replacement for the Amstrad ones:

- `nofdd`: ZX Spectrum +2E (without floppy disk drive).
- `fdd1`: ZX Spectrum +3E (with a single floppy disk drive).
- `fdd2`: ZX Spectrum +3E (with two floppy disk drives).

The +2A/+3 models boot Amstrad's original ROMs, unmodified:

- `plus2a`: ZX Spectrum +2A (v4.1 ROMs, no floppy disk drive).
- `plus2a-es`: ZX Spectrum +2A (Spanish v4.1 ROMs).
- `plus3-fdd1`, `plus3-fdd2`: ZX Spectrum +3 (v4.1 ROMs, one or two floppy disk drives).
- `plus3-v40-fdd1`, `plus3-v40-fdd2`: ZX Spectrum +3 v4.0 (the 1987 ROMs of the first +3s).
- `plus3-es-fdd1`, `plus3-es-fdd2`: ZX Spectrum +3 (Spanish v4.1 ROMs).

**Which one to pick.** Choose a +2A or +3 model when a program must behave exactly as on the
original machine: software that calls the Amstrad ROM directly, or needs a particular ROM version
or the Spanish ROMs. Choose a +2E or +3E model for everyday use: the +3E ROMs are compatible with
the Amstrad ones and add their own improvements. Running, debugging, injecting code, the tape
Loader, `.dsk` disks, snapshots and Klive state files work the same on every model.

A `.z80` or `.szx` snapshot of a +2A or +3 opens on a +2E/+3E model by default, with a warning that
it runs on the +E ROMs. When your project already uses a +2A or +3 model, the snapshot stays on it
and the warning goes. A snapshot saved from a +2A or +3 model is written as a +2A or +3.

## ZX Spectrum Next

Machine ID: `zxnext`

Available models: Only the original ZX Spectrum Next (KS2) model is available; it is still in development.

## Cambridge Z88

Machine ID: `z88`

Available models:
- `OZ50`: Cambridge Z88 (OZ v5.0B Int.)
- `OZ47`: Cambridge Z88 (OZ v4.7)
- `OZ40`: Cambridge Z88 (OZ v4.0 UK)
- `OZ40FI`: Cambridge Z88 (OZ v4.01 SE/FI)
- `OZ30`: Cambridge Z88 (OZ v3.0 UK)
- `OZ323IT`: Cambridge Z88 (OZ v3.23 IT)
- `OZ326FR`: Cambridge Z88 (OZ v3.26 FR)
- `OZ319ES`: Cambridge Z88 (OZ v3.19 ES)
- `OZ321DK`: Cambridge Z88 (OZ v3.21 DK)
- `OZ318DE`: Cambridge Z88 (OZ v3.18 DE)

Klive can open, run and debug Z88 snapshots saved by the OZvm emulator; see
[Using Z88 Snapshots](./howto/z88-snapshots).

## Sinclair ZX81

Machine ID: `zx81`

Available models:
- `zx81-16k`: Sinclair ZX81 with 16K RAM.
- `zx81-1k`: Sinclair ZX81 with its own 1K RAM.
- `zx81-64k`: Sinclair ZX81 with 64K RAM.
- `zx81-16k-us`: The US machine (Timex Sinclair 1000), NTSC, with 16K RAM.
- `zx81-1k-us`: The US machine with 1K RAM.

See [Using the ZX81 and ZX80](./howto/zx81).

## Sinclair ZX80

Machine ID: `zx80`

Available models:
- `zx80-16k`: Sinclair ZX80 with 16K RAM.
- `zx80-1k`: Sinclair ZX80 with its own 1K RAM.
- `zx80-8krom-16k`: Sinclair ZX80 with the 8K ROM upgrade (the ZX81 ROM) and 16K RAM.
