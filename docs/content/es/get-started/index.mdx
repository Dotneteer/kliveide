# Te damos la bienvenida a Klive

Klive es un emulador y un entorno de desarrollo integrado (IDE) en una sola app. Ejecuta el ZX Spectrum, el ZX Spectrum Next y otras máquinas Z80, y te permite escribir, compilar, ejecutar y depurar programas para ellas en ensamblador Z80 o en ZX BASIC. Funciona en macOS, Windows y Linux.

## Dos ventanas

Klive tiene dos ventanas que trabajan juntas:

- **El emulador** muestra la máquina: su pantalla, una barra de herramientas para iniciarla, pausarla y detenerla y, si lo deseas, un teclado virtual.
- **El IDE** es donde escribes el código: un explorador de proyectos, un editor de código, una línea de comandos y los paneles de depuración que muestran los registros de la máquina, su memoria y mucho más.

Puedes colocar las dos ventanas una al lado de la otra, o en dos monitores.

## Qué vas a hacer

Este tutorial dura unos 90 minutos. Cada página se apoya en la anterior, pero puedes parar después de cualquiera de ellas.
