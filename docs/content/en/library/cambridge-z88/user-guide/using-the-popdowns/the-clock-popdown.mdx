# The Clock popdown

The Clock popdown can be selectedwith <strong><Key k="square" /></strong>T whenever you need to see the correct time or date. The time is displayed in 24-hour format, and is accurate to within a few seconds per day. To set the time and date, see the details given in **[Set the clock](/en/library/cambridge-z88/user-guide/getting-started/up-and-running#set_the_clock)**,

<Shot src="z88-user-guide/using-the-popdowns/the-clock-popdown/clock-uk.webp" alt="Clock uk" width={640} />

Press <Key k="esc" /> to return to the current application.

Because you may be using the Clock pop-down to time something, the Cambridge Z88 will not switch off after the time-out period if the clock is displayed on the screen.

## International

If a different keyboard is selected in the Panel, the correct words are displayed for that language.
