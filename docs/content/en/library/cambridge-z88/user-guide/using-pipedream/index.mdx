# Section Two - Using PipeDream

This section will familiarise you with all the essential facilities provided by PipeDream, through a series of three simple worked examples:

- Design a party invitation, using PipeDream's text editing and page layout facilities.
- Set up a name and address list, using PipeDream's ability to organise information.
- Calculate home expenses, using PipeDream's facilities for working with tables of figures.
