# Fetching a file from the Flashcard

## Fetching a file from the Flashcard

Press <Key k="square" />J to start Flashstore

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-flashstore1.webp" alt="z88 flashstore1" width={640} />

Use the cursor keys <Key k="right" /> to move to the next window, then the <Key k="down" /> five times until it is over the **F** /flash.txt filename.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-flastore2.webp" alt="z88 flastore2" width={640} />

Press <Key k="enter" /> to select that file.<br />The following screen will be displayed. You can use the cursor keys to change the **Save to:** destination if desired, but :RAM.1/flash.txt is fine.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-flashstore3.webp" alt="z88 flashstore3" width={640} />

Press <Key k="enter" /> to confirm this.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-flashstore4.webp" alt="z88 flashstore4" width={640} />

This screen shows the file was copied to :RAM.1 successfully. Press either <Key k="space" /> or <Key k="enter" /> to resume as instructed.<br />The following screen is displayed.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-flastore2.webp" alt="z88 flastore2" width={640} />

As Flashstore is a Popdown, pressing <Key k="esc" /> exits the application and (in this case) returns to the INDEX.

<Shot src="z88-user-guide/getting-started/up-and-running/z88-index.webp" alt="z88 index" width={640} />
