# TOP

A function which returns the value of the first free location after the end of the current program.

The length of your program is given by TOP-PAGE.

PRINT TOP-PAGE

**Syntax**

\<n-var\>=TOP

**Associated Keywords**

PAGE, HIMEM, LOMEM
