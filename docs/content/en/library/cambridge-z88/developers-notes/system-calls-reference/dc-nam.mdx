# DC_Nam, Name current application

## Register parameters

```text
IN:
     HL = pointer to a null terminated name

OUT: -

Registers affected after return:
     A.BCDEHL/IXIY same
     .F....../.... different
```

## Notes

This provides text for the 'Your Ref.' column in the Index. Up to 15 characters can be displayed. Screen driver codes are ignored (Bold, underlined, etc.). Applications may use this call to define a "point-of-reference" description for it self when the Index popdown will be activated at a later time and the various running applications are listed. Pointer can be terminated with any control char ($00-$1F).
