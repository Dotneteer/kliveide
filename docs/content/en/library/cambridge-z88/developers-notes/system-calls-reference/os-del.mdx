# OS_Del, File delete

## Register parameters

```text
IN:
     IX = DOR handle

OUT, if call successful:
     Fc = 0
     IX = 0, DOR handle deleted.

OUT, if call failed:
     Fc = 1
     IX = 0
          A = RC_???

Registers changed after return:
     not documented.
```

## Notes

Internal operating system usage. Applications must use **[GN\_Del](/en/library/cambridge-z88/developers-notes/system-calls-reference/gn-del)**.
