# OS_Out, Write character to standard output

## Register parameters

```text
IN:
     A = character to be written
OUT:
     Fc = 0 always (error handler is never provoked)

Registers changed after return:
     A.BCDEHL/IXIY same
     .F....../.... different
```

## Notes

**[OS\_Out](https://cambridgez88.jira.com/wiki/pages/viewpage.action?pageId=97353756)** may also be used to write screen driver codes by writing them in a series of **[OS\_Out](https://cambridgez88.jira.com/wiki/pages/viewpage.action?pageId=97353756)** sequences, eg. 1, '2', '+', 'B' to switch on bold typeface.
