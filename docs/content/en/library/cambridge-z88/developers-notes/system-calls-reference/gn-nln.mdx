# GN_Nln, Send newline (CR/LF) to standard output

## Register parameters

```text
IN:
     -
OUT, if call successful:
     Fc = 0
OUT, if call failed:
     Fc = 1
     A = error code:
          RC_HAND ($08), bad handle (during re-direction)
          RC_WP ($14), write protected (during re-direction)

Registers changed after return:
     ..BCDEHL/IXIY same
     AF....../.... different
```

## Notes

This call is deprecated, use [**OS\_Nln**](/en/library/cambridge-z88/developers-notes/system-calls-reference/os-nln).

Error will only occur if rebinding has occurred.
