# OS_Mfr, Free (previously allocated block) memory

## Register parameters

```text
IN:
     IX = memory pool handle (returned from OS_Mop)
     BC = size of memory to release
     AHL = extended pointer address to beginning of memory block (A = bank)

OUT, if call successful:
     Fc = 0
OUT, if call failed:
     Fc = 1
     A = error code:
          RC_HAND ($08), bad handle
          RC_BAD ($04), invalid AHL/BC/IX combination
          RC_ERR ($0F), internal error (fatal)

Registers changed after return:
     ..BCDEHL/IXIY same
     AF....../.... different
```

## Notes

RC\_BAD may occur if the IX is the handle for another pool, or if A does not match pool bank number, or HL is not allocated in that pool.

## Bugs

Z88 crashes with a blinking "FAIL" message if you try to free memory that was already released with a previous **OS\_Mfr**.

Unrecoverable error returns a RC\_ERR fatal error since OZ 4.6
