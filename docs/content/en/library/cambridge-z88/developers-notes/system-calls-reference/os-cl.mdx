# OS_Cl, Internal close

## Register parameters

```text
IN:
     IX = file handle

OUT, if call successful:
     Fc = 0

OUT, if call failed:
     Fc = 1
     A = RC_NA, not available

Registers changed after return:
     ..BCDEHL/IXIY same
     AF....../.... different
```

## Notes

Internal operating system usage.

Applications must use **[GN\_Cl](/en/library/cambridge-z88/developers-notes/system-calls-reference/gn-cl)**. The file handle may not be reused (**[GN\_Cl](/en/library/cambridge-z88/developers-notes/system-calls-reference/gn-cl)** always returns IX = 0).
