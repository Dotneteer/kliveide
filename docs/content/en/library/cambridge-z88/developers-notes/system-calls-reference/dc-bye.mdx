# DC_Bye, Exit current process

## Register parameters

```text
IN:  A = return code ( Use RC_OK for a standard exit )

OUT: -
```

## Notes

Internal operating system usage. Does not return to caller. Applications use [**OS\_Bye**](/en/library/cambridge-z88/developers-notes/system-calls-reference/os-bye) to kill itself.<br />DC\_Bye returns to latest process or Index if none.
