# OS_Nln, send new line (CR/LF) to standard output

## Register parameters

```text
IN:  -

OUT: Fc = 0, success
     Fc = 1, failure and A = error code
          RC_HAND ($08), bad handle (during re-direction)
          RC_WP ($14), write protected (during re-direction)

Registers changed after return:
     ..BCDEHL/IXIY same
     AF....../.... different
```

Notes

This call replace [**GN\_Nln**](/en/library/cambridge-z88/developers-notes/system-calls-reference/gn-nln). It uses 2 bytes (instead of 3) and is significantly faster. Error will only occur if rebinding has occurred.
