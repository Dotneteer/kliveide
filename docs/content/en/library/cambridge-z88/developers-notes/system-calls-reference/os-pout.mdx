# OS_Pout, Write embedded string at (PC) to standard output.

## Register parameters

```text
IN:  -

OUT: Fc = 0, always (error handler is never provoked)

Registers changed after return:
   A.BCDEHL/IXIY same
   .F....../.... different
```

## Notes

- This call displays the null-terminated string following the call.
- This system call is only available in OZ release 4.2 and newer.
- Example :

```text
  ...
  OZ  OS_Pout
  defm 1,"7#4",$20+1,$20+0,$20+18,$20+8,$83
  defm 1,"2C4"
  defm 1,"2JC", 0
  ...
  ret
```
