# OS_Use, Fetch information about process card usage

## Register parameters

```text
IN:
     IX = static process id (handle)
OUT:
     Fc=0, A = card slot used (0 for internal slot, 1 for card 1... 4 for installed application device)
     Fc=1, A = RC_Hand, Bad handle
```

## Notes

Internal operating system usage. The API has been changed since OZ 4.6.
