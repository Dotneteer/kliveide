# GN_Lut, Lookup table facility

## Register parameters

**RST 20H, DEFW $8E09**

`IN: BHL = lookup table address (B=0, local)`<br /> `CDE = key (null terminated string) to search`<br /> `A = search options`<br /> `A0 = 1, case sensitive`

`A0 = 0, case insensitive`<br /><br /> `Lookup table format : keys have to be alphabetically sorted (ASCII sorted table if symbol are used)`<br /> `---------------------` <br /><br /> `defb N ; number of entries`<br /> `defm "key1",0, pointer1 ; first entry, null terminated followed by a 16bit pointer`<br /> `defm "key2",0, pointer2 ; second entry`<br /> `...`<br /> `defm "keyN",0, pointerN ; Nth and last entry`

`out,` `if` `successful:`

`Fc =` `0``, key found and associated pointer returned in HL`

`out,` `if` `failed:`

`Fc =` `1``,` `A = error code`

`RC_Eof, no matching string found`

`registers changed after` `return``:`

`A.BC.E../IXIY same`

`.F..D.HL/.... different`
