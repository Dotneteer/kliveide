# DC_Alt, Pass an alternative character

## Register parameters

```text
IN:  A = character to pass
     
OUT: -

Registers affected after return:
     ..BCDEHL/IXIY same
     AF....../.... different
```

## Notes

Internal operating system usage. Handles keys after square key i.e. starts new application or does redirection.
