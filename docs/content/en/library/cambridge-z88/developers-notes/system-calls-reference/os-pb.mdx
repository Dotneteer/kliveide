# OS_Pb, Write byte to file / device

## Register parameters

```text
IN:
     A = byte to be written to file / device
     IX = handle of file, device

OUT, if call successful:
     Fc = 0
OUT, if call failed:
     Fc = 1
     A = error code:
          RC_HAND ($08), bad handle
          RC_WP ($14), write protected
          RC_ESC ($01), escape, if device is :COM.0, :PRT.0
          RC_TIME ($02), if device :COM.0, :PRT.0
          RC_ROOM ($07), memory full on current device.

Registers changed after return:
     ..BCDEHL/IXIY same
     AF....../.... different
```

## Notes

Handle is acquired from **[GN\_Opf](/en/library/cambridge-z88/developers-notes/system-calls-reference/gn-opf)** (or **[OS\_Op](/en/library/cambridge-z88/developers-notes/system-calls-reference/os-op)** for internal use).
