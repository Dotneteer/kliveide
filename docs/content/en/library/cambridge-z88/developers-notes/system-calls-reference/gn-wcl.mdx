# GN_Wcl, Close wildcard handle

## Register parameters

```text
IN:
     IX = wildcard handle
OUT, if call successful:
     Fc = 0
     IX = 0
OUT, if call failed:
     Fc = 1
     A = error code:
          RC_HAND ($08), bad handle

Registers changed after return:
     ...C..HL/..IY same
     AFB.DE../IX.. different
```
