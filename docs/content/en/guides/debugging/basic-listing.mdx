# The BASIC Listing

One of Klive IDE's unique features is that it can list the BASIC program from within the running machine's memory. You can access this view with the **View | Machine Views | BASIC Listing** menu command:

<ClickableImage src="/images/working-with-ide/basic-list.png" width={640} />

The toolbar of the view contains these controls from left to right:
- **Refresh button**. You can refresh the BASIC list view.
- **Copy to Clipboard**. This button copies the current BASIC list to the clipboard.
- **Auto Refresh**. With this switch turned on (on by default), the IDE automatically reads and displays the current BASIC listing from the computer (even during program loading).
- **Show non-printable**. When this switch is turned on (off by default), the non-printable characters are displayed with their two-digit hexadecimal code with a `$` prefix and shaded background.
- **Use ZX Spectrum font**: This switch allows you to use the ZX Spectrum font instead of Klive's default monospace font.

If the BASIC listing is not available (or it is corrupted), this view may display one of these messages:
- **Machine OS has not been initialized yet**: This message appears while the machine's operating system is booting. It disappears when the machine reaches its main execution cycle.
- **BASIC program area is empty**: There is no BASIC program to list.
- **BASIC code corrupted or partially loaded**: When the BASIC program area is corrupted (some unexpected data is found) or the program is being loaded, the view displays this message at the location of the error.

## ZX81 and ZX80

The view lists ZX81 and ZX80 programs too, each in its own format, and spaces the keywords the
way the machine's own `LIST` does. A ZX80 with the 8K ROM upgrade is listed as a ZX81. On these
machines the font switch is labelled **Use Sinclair font**.

The ROMs list a line up to its NEW LINE character, so a NEW LINE stored inside a `REM` (machine-code
loaders often have one) starts a new row, often with an odd line number such as `E393`. The view shows
it the same way the machine's `LIST` does. A character `LIST` cannot print appears as `?`, or as its
code when **Show non-printable** is on.

## HT-1080Z

On the HT-1080Z the view lists the Level II BASIC program the way the machine's own `LIST` does:
keywords as stored, with no spaces added, `ELSE` and `'` without the colon BASIC keeps before them.
It uses the model's own characters, so Series II's accented letters show as such, and on the /64 a
backtick and a key show as the Hungarian or mathematical character they stand for. The font switch
is not offered: the Sinclair fonts have no such characters. See
[Using the HT-1080Z](/en/guides/emulator/ht1080z#debugging).
