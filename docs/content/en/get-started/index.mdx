# Welcome to Klive

Klive is an emulator and an Integrated Development Environment (IDE) in one app. It runs the ZX Spectrum, the ZX Spectrum Next and several other Z80 machines, and it lets you write, build, run and debug programs for them in Z80 assembly or ZX BASIC. It runs on macOS, Windows and Linux.

## Windows and monitors

Klive starts with two main windows that work together:

- **The emulator** shows the machine: its screen, a toolbar to start, pause and stop it, and, if you want one, a virtual keyboard.
- **The IDE** is where you write code: a project explorer, a code editor, a command prompt, and the debugging panels that show the machine's registers, memory and more.

You are not limited to these two. Right-click a document's tab in the IDE and choose **Pop Out to Window** to move that document into a window of its own: a source file, the Memory View or the Disassembly View, for example. Up to four documents can have their own windows at a time. A popped-out document works as it does in the IDE, with its breakpoints, the execution point and its keyboard shortcuts, and its **Dock** button puts it back into the IDE.

Klive uses every monitor your computer has. You can keep the emulator on one screen, the IDE on another, and the code you are debugging next to the emulator. Klive remembers where its windows were and opens them there next time. [A document in its own window](/en/guides/editing/editor/#a-document-in-its-own-window) has the details.
