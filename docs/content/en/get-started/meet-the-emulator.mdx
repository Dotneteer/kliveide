# Meet the emulator

When Klive starts, it shows the emulator window with a machine that is turned off. This page shows you how to switch it on, type a program, and pick another machine.

1. The toolbar starts, pauses, stops and restarts the machine. The first button, the green triangle, is **Run Machine**.
2. The screen. Until you start the machine, it shows a hint about how to start it.

## Start the machine

Press <kbd>F5</kbd>, click **Run Machine** on the toolbar, or choose **Machine › Start**. After a moment the ZX Spectrum shows its copyright message, just as the real computer did in 1982.

  src="get-started/emulator-running.webp"

## Type a BASIC program

Click the emulator's screen so it gets your keystrokes. The ZX Spectrum 48K enters BASIC **keywords** with a single key: at the start of a line, the cursor shows **K**, and pressing <kbd>P</kbd> types the whole word `PRINT`.

<Steps>

### Type the line

Type <kbd>1</kbd> <kbd>0</kbd>, then <kbd>P</kbd> for `PRINT`. For the quotation mark, hold **Symbol Shift** and press <kbd>P</kbd>. Klive's Symbol Shift is the **right Alt** key (the right **Option** key on a Mac). Type `hello`, then the closing quotation mark the same way, and press <kbd>Enter</kbd>.

<Shot
  src="get-started/emulator-basic-line.webp"
  alt="The BASIC line 10 PRINT &quot;hello&quot; in the program listing"
  figure="2.3"
  caption="The line is in the program"
  width={620}
/>

### Run it

Press <kbd>R</kbd>, which types `RUN`, then <kbd>Enter</kbd>. The program prints `hello` and reports `0 OK, 10:1`: it finished without an error, at line 10, statement 1.

<Shot
  src="get-started/emulator-hello.webp"
  alt="The program has printed hello"
  figure="2.4"
  caption="Your first program ran"
  width={620}
/>

</Steps>

<Callout type="info" emoji="💡">
If the keyword keys are hard to remember, show the **virtual keyboard** with the keyboard button on the emulator's toolbar or with **View › Virtual Keyboard**. It shows every keyword, and you can click its keys. See [The keyboard](/en/guides/emulator/keyboard/).
</Callout>

## Control the machine

| To | Press | Toolbar |
| --- | --- | --- |
| Start or continue | <kbd>F5</kbd> | **Run Machine** (green triangle) |
| Pause | <kbd>Shift</kbd>+<kbd>F5</kbd> | **Pause** |
| Stop (switch off) | <kbd>F4</kbd> | **Stop** |
| Restart | <kbd>Shift</kbd>+<kbd>F4</kbd> | **Restart** |

A stopped machine cannot continue, but you can still look at its memory and registers in the IDE.

## Choose another machine

**Machine › Machine Type** lists your favourite machines. **Select machine…** (<kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> on macOS, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> on Windows and Linux) opens a dialog with every model Klive emulates. You can also click the machine's name at the right end of the emulator's status bar.

<Shot
  src="get-started/select-machine.webp"
  alt="The Select machine dialog with the ZX Spectrum 48K selected"
  figure="2.5"

  width={760}
/>

Type in the filter box to find a model (for example `128K` or `NTSC`), select it to see its details, and double-click it to switch. The star adds a model to the **Machine Type** menu. [Machine types](/en/reference/machine-types/) lists every machine and model.
