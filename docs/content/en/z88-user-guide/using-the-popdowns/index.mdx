# Section Four - Using the popdowns

The Cambridge Z88 popdowns are utility programs that you can make use of while you are working within another application, such as PipeDream, the Diary, or BBC BASIC. They pop down over your application screen, and disappear again when you press <Key k="esc" /> to return to the application.

## Using popdowns

You can either call a popdown by pressing the <Key k="square" /> key combination given above, or from the Index (using <Key k="index" /> key) as follows:

### Calling a popdown from the Index

Highlight the popdown's name on the `APPLICATIONS` list. You can move the bar highlighting items on this menu by pressing the <Key k="up" /> and <Key k="down" />keys at the bottom right of the keyboard. If you move the bar too far, press <Key k="up" /> to go up again. Then press <Key k="enter" /> to run the popdown you have selected.
