# The Index

The Index popdown allows you to call up Cambridge Z88 applications or popdowns, or to return to any activity that you were previously working on.

To see the Index screen at any time, press the <Key k="index" /> key at the lower left of the keyboard. <br />To return to an application from the Index, press <Key k="esc" />. The components of the Index screen are identified below:

<Shot src="z88-user-guide/getting-started/basic-concepts/the-index/the-index.webp" alt="The Index" width={694} />

The right-hand edge of the screen is reserved for status information from the Cambridge Z88 operating system. It displays OZ when the Cambridge Z88 is ready for use.
