# Entering an application

To enter an application, or a popdown, you simply have to select its name on the APPLICATIONS menu by moving the highlighting bar up and down with the cursor keys <Key k="up" />and <Key k="down" />:

<Shot src="z88-user-guide/getting-started/basic-concepts/entering-an-application/selectactivity.webp" alt="selectactivity.png" width={670} />

When the bar reaches the bottom of the screen, the list scrolls up to show the remaining options. Having selected the one you want press the <Key k="enter" /> key to enter it. You can also use the application shortcut, listed to the right of the name. Here's the complete list of available application shortcuts:

## Creating a new activity

Entering PipeDream or BBC BASIC from the Index APPLICATIONS list creates a new, blank document.

For example, to enter PipeDream, starting with a new blank document, move the highlighting bar until `PipeDream` is selected, and press the <Key k="enter" /> key; you will then see the PipeDream screen:
