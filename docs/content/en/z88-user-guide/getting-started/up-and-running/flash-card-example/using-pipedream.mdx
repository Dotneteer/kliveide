# Using Pipedream

## Using Pipedream

Let's have a look at the file in Pipedream by selecting <Key k="square" />P

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-pipedream1.webp" alt="z88 pipedream1" width={640} />

Select File Load either <br />pressing the <Key k="menu" /> key 4 times to display the FILES menu, then selecting it with the <Key k="enter" /> key

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-pipedream-menu-fl.webp" alt="z88 pipedream menu fl" width={640} />

or using the short-form key presses of <Key k="diamond" />FL

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-pipedream-fl.webp" alt="z88 pipedream fl" width={640} />

### Using the Filer with Pipedream

To save typing in the file name, the Filer may be used to select this. Select the Filer <Key k="square" />F

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-pipedream-fl-filer.webp" alt="z88 pipedream fl filer" width={640} />

Move the cursor to the right using <Key k="right" /> key.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-pipedream-filer-flash.webp" alt="z88 pipedream filer flash" width={640} />

Select that file by pressing the <Key k="enter" /> key.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-pipedream-filer-flash-select.webp" alt="z88 pipedream filer flash select" width={640} />

Note that a mark to the left of the file name indicating that this file has been selected. <br />Press the <Key k="esc" /> key to return to Pipedream.<br />Note that the :RAM.1/flash.txt has been filled in.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-pipedream-fl-flash.webp" alt="z88 pipedream fl flash" width={640} />

This text file is a 'Plain Text' file so before the file is loaded the 'Load as plain text' needs to changed to 'Yes.'<br />Move the cursor down 3 lines <Key k="down" />and use the 'Y' key to change it.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-pipedream-fl-flash-pt.webp" alt="z88 pipedream fl flash pt" width={640} />

Finally use the <Key k="enter" /> key to start loading in the file.<br />The following screen is displayed showing the start of the file.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-pipedream-fl-flash-top.webp" alt="z88 pipedream fl flash top" width={640} />

Note the page map is shown on the right-hand side with a small vertical bar (just next to the OZ symbol). <br />This bar shows you which part of the page is being viewed. In this case it is the top 6 lines. <br />By pressing <Key k="diamond" /><Key k="down" /> you can go straight to the end of the file.

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-pipedream-fl-flash-bot.webp" alt="z88 pipedream fl flash bot" width={640} />

If this has worked for you, this is an excellent test for the RAM as it has been tested at both saving a file to it as well as it being used in the Pipedream application.

When you have finished with this file it is a good idea to kill this activity to release the memory it is using.<br />Pressing the <Key k="index" /> key will display the following:-

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-index-kill1.webp" alt="z88 index kill1" width={640} />

Move the cursor to the right <Key k="right" /> to select the desired suspended activity to kill, then press <Key k="diamond" />KILL

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-index-kill2.webp" alt="z88 index kill2" width={640} />

Note that the <Key k="diamond" />KILL menu command cannot be used e.g. <Key k="menu" /> moving the cursor across and then the <Key k="enter" /> key

<Shot src="z88-user-guide/getting-started/up-and-running/flash-card-example/z88-index-killmenu.webp" alt="z88 index killmenu" width={640} />

This is done to ensure that you really wanted to KILL the suspended application.
