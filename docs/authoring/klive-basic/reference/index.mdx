# Klive BASIC language

Klive BASIC is the ZX BASIC compiler built into Klive IDE. It compiles a BASIC program to Z80 machine code for the ZX Spectrum 48K, 128K and +3 and the ZX Spectrum Next. The language is compatible with Boriel ZX BASIC 1.19, and it adds NextBuild's `CODEBANK` extension for the ZX Spectrum Next.

This reference describes the language. To build, run and debug a program in the IDE, read [Klive BASIC](/en/guides/languages/klive-basic/).

## A first program

```zxbasic
' Count the moves of the towers of Hanoi
DIM moves AS UInteger

SUB hanoi(n AS UByte, from AS UByte, dest AS UByte, via AS UByte)
  IF n = 0 THEN RETURN
  hanoi(n - 1, from, via, dest)
  moves = moves + 1
  hanoi(n - 1, via, dest, from)
END SUB

hanoi(8, 1, 3, 2)
PRINT moves
```

The program prints `255`.

## Program structure

A program is a sequence of lines. Each line holds zero or more statements separated by `:`. Line numbers are optional, and so are labels. Execution starts at the first statement of the main program and runs to its end, or to `END` or `STOP`.

A program contains:

- **Declarations**: `DIM` for variables and arrays, `CONST` for constants, `DECLARE` for forward declarations.
- **Routines**: `SUB` (no result) and `FUNCTION` (returns a value). They have parameters and local variables, and they can call themselves.
- **Statements** of the main program: assignments, control flow, `PRINT`, graphics, sound and I/O.
- **Preprocessor lines**, which start with `#`: `#include`, `#define`, `#if` and `#pragma`.
- **Header options** in the comment lines at the top of the build root file, written as `'@name value`.
- **ASM blocks** of Z80 assembly.

## What differs from Sinclair BASIC

Klive BASIC looks like Sinclair BASIC, but it is a compiled language. These are the main differences:

| Topic | Klive BASIC |
| --- | --- |
| Line numbers | Optional. A line number is a label; the order of line numbers does not matter. |
| Labels | A name followed by `:` at the start of a line. `GOTO`, `GOSUB` and `RESTORE` accept labels and line numbers. |
| Types | Every variable has a type: `Byte`, `UByte`, `Integer`, `UInteger`, `Long`, `ULong`, `Fixed`, `Float` or `String`. An undeclared variable takes its type from the first value it gets. |
| Routines | `SUB` and `FUNCTION` with typed parameters, `BYVAL` and `BYREF` passing, local variables and recursion. |
| Blocks | Multi-line `IF` ... `ELSEIF` ... `ELSE` ... `END IF`, `WHILE` ... `END WHILE`, `DO` ... `LOOP`, and `EXIT` and `CONTINUE` for loops. |
| Names | Identifiers are case-sensitive by default; keywords are not. Names are made of letters, digits and `_`. |
| Indexing | Arrays and strings count from 0 by default. The `array-base` and `string-base` options change this to 1. |
| Arrays | `DIM a(10)` declares 11 elements (0 to 10) with the default base. Bounds can be given as `DIM a(1 TO 10)`. |
| Operators | Bitwise operators (`bAND`, `bOR`, `bXOR`, `bNOT`, `SHL`, `SHR`) in addition to the logical `AND`, `OR`, `XOR` and `NOT`. |
| `PRINT` | All 24 rows are usable. The apostrophe is not a separator: it starts a comment. |
| `PLOT` | (0, 0) is the bottom-left pixel and all 192 rows are usable. |
| Library functions | `INPUT`, `ATTR`, `POINT` and `SCREEN$` come from the standard library, included with `#include`. `INPUT` is a function that returns a string, not a statement. |

The `sinclair-compatible` header option sets both bases to 1, makes names case-insensitive, and includes `ATTR`, `POINT` and `SCREEN$` without an `#include`.

## Where Klive BASIC differs from zxbc

Klive BASIC gives the same results as Boriel's `zxbc` 1.19, except in a short list of cases where `zxbc`'s result is wrong, depends on leftover values, or `zxbc` fails while compiling. The list is in the user guide: [Where Klive BASIC differs from zxbc](/en/guides/languages/klive-basic/#where-klive-basic-differs-from-zxbc). This reference describes Klive BASIC's behaviour.
