The retro computer IDE for Z80 machines

Klive IDE is a retro computer emulator and Integrated Development Environment running on Mac and Windows.

DownloadRead the docs

Retro emulators

ZX Spectrum 48K, 128K, +2E/+3E and Cambridge Z88, with the ZX Spectrum Next on the way.

IDE and debugger

Breakpoints, stepping, memory and disassembly views, CPU and machine state panels, and a multi-pane code editor.

Z80 assembler

A full-featured Klive Z80 assembler with macros, structs and ZX Spectrum Next extensions.

ZX BASIC

Write, build and debug ZX BASIC programs right next to your assembly code.

Klive IDE is open source. View it on GitHub.
