What makes Klive different

All in one

One app. Zero glue.

Start from a template for the 48K, 128K, +3E, Next or Z88 and press Run. Elsewhere this takes an assembler, an editor, an emulator and a debugger bridge, configured by hand.

  • Compile, inject, run and debug with one click
  • Project templates for every machine
  • Works with sjasmplus, Boriel BASIC, z88dk and PASTA/80 when you want them

ZX BASIC

Step through your BASIC, line by line

Klive's built-in ZX BASIC compiler, compatible with Boriel ZX BASIC, debugs at the source level: breakpoints on statements, Step Over and Step Into, a real call stack, live variables, and stops on runtime errors.

  • No installation: the compiler is built in
  • Compatible with Boriel ZX BASIC and NextBuild's CODEBANK
  • Editor help: completion, go to definition, rename
Read more →
ZX Spectrum Next

Speaks Next natively

Break when a program writes a Next register, with value and mask filters and old-to-new values. Set breakpoints on banks rather than addresses, program the DMA with a readable syntax, and build .nex files with palettes, Copper lists and loading bars.

  • Live views of the sprites, the Copper and the video layers
  • Sprite and palette editors
  • NextZXOS boots from an emulated SD card
Read more →
Disassembly

Disassembly that explains itself

Every conditional branch shows whether it will be taken and what it costs in T-states, worked out from the live flags. System variables appear by name, and you can measure the T-states between any two points.

  • Banked memory shown per bank
  • Labels and comments you add, everywhere
  • A ULA view of the beam, contention and the floating bus
Read more →
Reverse engineering

Open a .nex. Understand it.

Debug any NEX file with no project and stop at its entry point. Compare a bank with the file on disk, name routines as you find them, and keep your labels, comments and data regions in a file that is there next time.

  • Break at the entry point
  • Annotations in a sidecar file
  • Copper lists and DMA programs decoded
