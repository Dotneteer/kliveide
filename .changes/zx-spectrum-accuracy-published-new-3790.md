**ZX Spectrum accuracy, published:** a new documentation page, "ZX Spectrum: how Klive's accuracy is tested", lists the community's timing test programs Klive's 48K and 128K pass - ZX Spectrum Timing Tests 48K and 128K, HALT2INT, Float48K, FloatSpy, Border Time, Screen Time and Timing Test - with what each one checks and Klive's own screen running it. HALT2INT's results stand beside its author's photos of a real early and a real late 48K, and the page says what the tests found and what is not proven yet. The landing page links to it under "Tested against real hardware".
