**C with z88dk.** Klive builds, runs, debugs and exports C programs with z88dk: a z88dk Integration dialog (Settings › Integrations or `z88dk-setup`) finds an installation or downloads a release from GitHub, `.c` build roots compile for the running machine (every ZX Spectrum family machine, from the 48K, 128K, Pentagon 128 and +2A/+3/+2E/+3E to the Timex models, the Scorpion and the Next, and the ZX80/ZX81 and Cambridge Z88 application cards), errors reach the Problems view, breakpoints stop on C lines, Step Into/Over/Out step C statements, the Call Stack and Variables panels show functions, parameters, locals and globals, Export copies the native file z88dk wrote, new `z88-dk` project templates cover every supported machine, and a build warns when z88dk's ZX Spectrum Next startup code would run into `printf`'s format table, which can stop the program from starting.
