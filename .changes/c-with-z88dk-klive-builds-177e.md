**C with z88dk.** Klive builds, runs, debugs and exports C programs with z88dk: a z88dk Integration dialog (Settings › Integrations or `z88dk-setup`) finds an installation or downloads a release from GitHub, `.c` build roots compile for the running machine (ZX Spectrum 48K/128K/+3, Timex, Next, ZX80/ZX81, and Cambridge Z88 application cards), errors reach the Problems view, breakpoints stop on C lines, Step Into/Over/Out step C statements, the Call Stack and Variables panels show functions, parameters, locals and globals, Export copies the native file z88dk wrote, and new `z88-dk` project templates cover every supported machine.
