**One colour set for every disassembly:** the Disassembly view, every file viewer and ROM page
(read-only ones included), the execution history, the Breakpoints panel, the annotation dialogs, the
Copper list and the `dis` and `history` commands now show an instruction the same way: the address
and opcodes in the accent colours, the instruction in bold, every label (generated or named) in the
label colour, a name in an operand in the operand colour, data in the directive colour and comments
green and italic.
