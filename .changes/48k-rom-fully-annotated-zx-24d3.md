**The 48K ROM fully annotated:** the ZX Spectrum 48K BASIC ROM's annotations, written for Klive from the ROM's own bytes, now cover the whole ROM: every call and jump target has a label (1,042 in all), every labelled routine has a synopsis saying what it does, takes and returns, and the lines whose purpose is not obvious carry a comment (4,886). Tables, messages, calculator literals and the character set are marked as data, so the Disassembly view reads the ROM as code and data throughout, and Export as source turns it into a commented listing that reassembles byte for byte. The labels also apply to the 128K's copy of the 48K BASIC ROM, wherever its bytes match.
