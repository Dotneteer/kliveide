**The 48K ROM fully annotated:** the ZX Spectrum 48K BASIC ROM's annotations, written for Klive from the ROM's own bytes, now cover the whole ROM: every call and jump target has a label (1,043 labels in all), every labelled routine has a synopsis saying what it does, takes and returns, and the lines whose purpose is not obvious carry a comment (4,886). Tables, messages and calculator literals are marked as data, and the character set is listed one binary pixel row per line with each character named, as in the ZX80 and ZX81 ROMs, so the Disassembly view reads the ROM as code and data throughout, and Export as source turns it into a commented listing that reassembles byte for byte. The labels also apply to the 128K's copy of the 48K BASIC ROM, wherever its bytes match.
