**The ZX Spectrum Next's ROMs fully annotated:** the four pages of NextZXOS, the alternate ROM, the DivMMC ROM and the Multiface ROM now have annotations at the same completeness as the 48K ROM's: every routine is labelled and described and its lines are commented, from start-up, the menus and the Browser to NextBASIC's commands and editor, sprites, tiles, layers and PLAY, the DOS calls and the SD card driver, the FAT file system and the NMI menu. The Disassembly view lists the address or byte that follows a call into another ROM or into the DivMMC's memory as data, so the code after it lines up, and Export as source reassembles each ROM byte for byte. The enNextLG.rom variant shares them.
