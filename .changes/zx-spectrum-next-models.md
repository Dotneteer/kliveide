**ZX Spectrum Next models:** the Next comes as two models, KS2 with core 3.02.01 and KS2 with core
3.02.04, each with its own emulated hardware, NextZXOS release (2.08 and 2.10), ROMs, default SD card
and Next Registers descriptions. Pick one in Select Machine or New Project; new projects start on
core 3.02.04, and projects saved earlier open on core 3.02.01. A state file or debug recording saved
on one model is refused by the other, with a message that names both. Debug › ROM Annotations
has NextZXOS 2.10's ROMs at level 2 (every call and jump target labelled, every label described), like
2.08's.
