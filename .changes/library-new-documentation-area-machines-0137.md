**The Library, a new documentation area for the machines' own manuals:** the last navbar tab of kliveide.net holds the manuals of the machines Klive emulates, one folder per machine. It starts with the Cambridge Z88: the **Z88 User Guide** (moved here; its old addresses redirect) and the newly imported **Z88 Developers' Notes** - writing applications for OZ, all of its system calls, memory management, the BLINK chip, the hardware and the Z80 instruction set. Both are in the site search, links between them stay on the site, and the landing page's header and the Cambridge Z88 machine guide link to the Library.
